This is a local trial candidate, not a public release or a root-cause claim.

intent, exact stale-record proof/refresh repair, and bounded optional diagnostics.

`WM_AUTHOR_DIAGNOSTICS=1` enables authenticated bootstrap metadata and the quiet
export row. Export explicitly hands a bounded, source-bound JSON file to the
browser; a check mark does not prove the file was saved. Renderer and Host clocks
remain separate. No parameter values, commands, tokens or chat content are logged.

at its root. Candidate acceptance is still pending. Back up current data only
after fresh convenience/normal-exit confirmation; the trial defaults to restoring
daily rc.56 and this round's settings. Do not reuse old authorization or backups.

inputs, not the shared rc.30/Trace development tree. Native assets are unchanged.
