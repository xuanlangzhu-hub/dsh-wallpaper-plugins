# 实际开发源码核验

隔离d轮候选通过后，实际开发源按同一注释配方接入。`run.py` 保留为历史隔离配方；实际路径检查使用：

```powershell
python -X utf8 dsh-whale-mist/qa/typescript-probe-log/check-source.py --output .tmp/probe-log-source-check-1
```

输出目录必须全新。此检查只读开发源，不负责应用修改；它先确认实际源与已审隔离候选文本相同（允许原CRLF行尾保持），旧377基线除明确的日志源外全部一致。复用已固定TypeScript5.9.3归档SRI和解压文件证明，再将正例／9负例／原8日志回归及8基线对照重新绑定到真实开发路径。

严格noEmit、57个ES2022标准库，无DOM／Node／SDK类型，无应用／原生执行。语法树比较与3个逻辑变异检查复用已审验证器。各阶段20秒、总65秒，Node测试单进程／单项3秒，不自动重试。

这些配方绑定当前已审模块与保护快照，不是可以忽略未来其它改动的全仓CI。接下来可统一两个已接入模块的开发检查入口，届时显式更新审定保护基线并复用公共执行逻辑；不能为了通过旧历史脚本删掉门禁。
