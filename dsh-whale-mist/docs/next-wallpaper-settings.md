## 设置与行为

在现有鲸系外观背景入口加入“Wallpaper Engine（实验）”，注明首版已验证场景和预览时限。
复用亮度、主题色遮罩、模糊、界面不透明度及 cover 缩放逻辑；避免为 WE 再做一套外观参数。

- 默认不选择 WE、不自动弹源窗口；安装候选包本身不开始采集。
- 选择 WE 后提供明确的开始预览、停止、重新开始以及简短运行/错误状态。
- 同一时刻只有一种活动背景。切到无/图片/视频时，先停止 WE，再呈现所选背景。
- 保存来源与参数，重载后保留这些选择。首版仍由用户点击开始预览；不要伪装成全天持续播放。
- 每次实际开始建立新实例、新唯一窗口名。重复开始、快速切换、启动途中停止不能留下额外资源。
- 停止、到达预览时限、失败、停用和退出都要清理本轮源窗口及采集进程。
- 出错保持聊天界面可用，保留用户参数，给出明确的重试入口；不无限自动重启。
- 普通网页、非 Windows、非官方 Desktop 或 WE/原生依赖不可用时，保留其它外观功能，说明 WE 当前不可用。

## 实现边界

复用或提取 0.0.7 的桥接、协议、日志和原生代码，避免维护两个不同的生命周期实现。
新入口不依赖固定 TEMP 文件、F: 开发源码目录或历史 PID/HWND。
Host 从插件自身打包位置找到 helper；保持 Windows 图标辅助程序原有行为。

客户端只提交受约束的操作和参数。首版场景通过 Host 白名单标识映射到已验证工程，
不新增接受任意 helper 路径、输出目录、命令或 HWND 的 HTTP 接口。
本机 Lucy 工程不存在时给出缺失提示；不要为了通用壁纸选择器把任意路径执行能力暴露给前端。
本机样例依赖须写明，完整壁纸库选择与安装位置自动发现留待后续。

把画面接入现有背景层与恢复逻辑，解决 Whale 配色/清晰画布覆盖问题。
保留输入框与菜单可读性，并核对减少透明度/高对比度偏好。
不要直接把 QA 中更高优先级的透明规则复制成永久覆盖。

本机候选包应包含实际需要的原生文件及运行依赖说明；不能只包含一个依赖开发机 DLL 的 EXE。
若短时间内无法正确打包依赖，保留代码并明确标出阻塞，不把仅源码可运行称为可安装交付。
预览日志放受控运行数据目录，保留失败证据并限制体积；不要长时间写 JPEG 帧文件。
