# rc.5 官方 Desktop 人工协作验收

前置：wallpaper-settings-rc5-review.md 的代码和无窗口复审通过。
候选包：release/plugins/dsh-whale-mist-0.6.0-rc.5.tgz，单 Lucy 场景，.NET 10 依赖不变。
本文件只规定下一轮验收，不表示已获本次桌面操作便利确认。

1. 用户确认当前方便并暂停 DS/其它界面助手。用户负责所有点击，Codex 在 DSH 外部准备与核验。
2. 记录当前主题/背景与原 WE 进程身份，备份现有 Profile 四份文件和外观设置；保留本地媒体资产。
   不能把历史 PID、路径或配置当作当前值。
3. 用户经应用菜单正常退出 DSH；外部助手安装 rc.5，核对版本化 tgz，再由用户重开。
   原生与图标辅助程序属于同一主题包，避免运行中升级产生文件占用。
4. 确认现有主题/输入/图片视频入口正常，尚未主动开始 WE 时不创建源窗口。
5. 用户在鲸系外观选择 Wallpaper Engine（实验），点开始。观察真实动态画面 45–60 秒，
   重点检查超过 20 秒仍播放，计数与倒计时更新，聊天文字可读。
   顺手调整亮度/遮罩/界面不透明度，做一次缩放和最小化恢复、输入几个字但不发送。
6. 点停止：确认恢复主题、本轮窗口和采集进程在 10 秒内消失。
   再次开始要建立新的唯一实例；重新开始应先清理旧实例。
   切到无/图片/视频时确认 WE 清理，选择与参数重载后保存，重载不自动播放。
7. 最后一轮由用户在播放时经应用菜单正常退出 DSH；
   外部观察者在退出前已记录该轮身份，在退出后确认窗口/进程消失、原 WE 保留。
   不由 DS 自行退出它的宿主，不强杀 DSH 或 wallpaper64 做故障注入。
8. 若有明确失效，不反复重做全部成功场景；记录原始错误、版本、运行目录及该轮身份，交回修复。
   有效旧自动故障证据可以引用，本轮不要求重复所有原生实验。
9. 最后依据本轮约定恢复原日常版本与外观：先在 DSH 已关闭时处理版本，再重开，
   只撤销本轮改动，保留用户期间产生的有效数据和全部引用包。
   若用户明确选择保留候选版，则记录这一选择；不能默认替用户长期留用。
10. 新增 wallpaper-settings-desktop-acceptance.md，区分用户实机观察、后台关闭证据与已有模拟结果。
    更新 NEXT_TASK.md 为实机通过/失败及具体剩余项；不把候选预览宣布为完整正式 WE 接入。

资源清理严格按本轮唯一窗口名和进程身份核对，原桌面壁纸/全局设置保持原样。
不运行旧 desktop-watch.ps1，不使用 browser-* 等通配符清理证据。
临时 profile 若确需清理，只使用自己创建、已验证为目录的精确路径；先保留输出。
