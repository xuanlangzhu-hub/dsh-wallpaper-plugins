## 行为与布局

作者数值行保留左侧标签和下方滑块，将右侧只读数值换成紧凑输入框；继承侧栏字体、文字/边框/强调色，不新增保存或应用按钮。色彩通道保持原有布局。

| 操作 | 行为 |
| --- | --- |
| 输入有效数字 | 只预览，滑块同步；不立即下发 |
| Enter或正常移开焦点 | 校验最终原文，只提交一次数值差量；等价值不提交 |
| 空值、不完整、越界、非整数或不符合步长 | 本地标错，不发送之前的有效前缀；失焦取消并恢复插件记录 |
| Esc、窗口失焦、隐藏/关闭、切目标或代次 | 取消未完成编辑，无回退命令，迟到事件不能重启提交 |
| 输入后直接点击滑块 | 先完成或取消文本编辑，再交接同字段所有权，一次点击即可调整 |
| 上一条仍在执行 | 新输入保持本地原文，已完成的新值按既有规则合并串行下发 |

输入框使用text加decimal输入提示，保留空串、负号、不完整指数等中间输入，不依赖浏览器number控件先行清洗。接受最多64字符的完整十进制/科学计数法，拒绝空白、十六进制、NaN/Infinity和非有限数；不截断、不钳制、不自动舍入。最终有限范围、fraction和step继续由原`validateAuthorValue`验证。输入`03`或`3e0`可保留原文到完成，完成后显示规范数值`3`。

修改滑块会同步空闲数值框；在另一处仍有有效本地编辑时，不能抢走其票据。无效输入取消后，再次有效拖动会清除过期的本地错误提示。初始值仍为作者默认值或插件记录，**不是WE实时读回**；下发勾号不代表画面效果验收。
