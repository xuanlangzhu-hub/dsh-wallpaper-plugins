# 壁纸设置侧栏改版要求

2026-10-21，来自用户本轮真实使用反馈。当前独立设置页难用，后续需要整体改版；本文件登记产品方向，尚未实现或实机验收。

## 位置与承载：桌面端最右侧

- 用户补充截图指向DSH顶栏最右侧的“打开侧边栏”（图中快捷键Ctrl+Alt+B）。目标是与桌面端主界面融为一体的最右侧栏，有统一边界、层级和开关体验；不是左侧导航，也不是再做一个覆盖聊天的浮层或默认弹出外部浏览器窗。
- 调整参数时仍可观察壁纸即时效果，减少进入通用设置再退出的往返。接宿主侧栏的真实扩展能力须先核实；截图中的入口不等于已证明插件可注册到其中，不能虚构API、改官方安装或抢占现有侧栏内容来假装完成集成。
- 侧栏颜色、文字、强调色及透明度随DSH主题和外观设置一起变化，不能固定一套不协调的独立底色。
- 若保留“弹出独立窗口”，弹出成功后主窗口对应设置面板应收起，避免两块重复占空间；吸附成功后恢复侧栏并关闭独立窗口。失败或退出未确认则保留真实状态，不能假称已关闭。

## 内容布局：先规划，再重做

- 用户评价现状像随手摆放，需要按使用顺序规划整个插件UI、按钮位置和交互，不只给原长表单换皮。下列为后续设计起点，不是已实现布局。
- 常用入口优先：清楚呈现当前壁纸、播放/停止、切换壁纸与正在调整的参数；图库选择和当前壁纸详情分层，避免所有项目挤在同一个连续滚动页。
- 插件外观参数与当前壁纸作者参数分组，名称和范围明确；不得把主题调节与作者参数混在一起，让用户不知道修改对象。
- 低频、高级、实验性和当前暂时无用的项移到二级入口或收起，不占默认操作区。“刷新草稿”、清理诊断、内部状态和未接入功能等不能作为日常首屏主操作；必要的故障恢复入口在出错时出现。
- 当前壁纸不支持的功能不放一个不可用按钮充数；给必要且简短的空状态。作者原始字段名/翻译token不能成为常用界面的最终标签。
- 重复的播放、应用或跳转入口需要合并。布局应在侧栏宽度、窗口变窄、长标题、很多作者参数时仍保持主次和可读性，避免按钮堆叠与重要操作滚出可视区。

## 作者参数：以直接生效为目标

- 用户以Wallpaper Engine“勾选即生效”为明确参照。默认日常流程改为修改参数后直接应用当前活动壁纸，不再要求“保存草稿→应用到当前壁纸”，也不将三个草稿按钮保留在主操作区。这条覆盖此前“是否即时应用另行设计”的暂定表述。
- 开关点击后提交最终值；滑块在合适的交互完成点下发并合并中间变化；文本/数值在有效提交时生效。不得每次按键或每个拖动像素都启动子进程，也不能为节流无期限等待。
- 控件首先有即时按下/切换反馈，再呈现处理中与结果；快速连改按顺序或合并到最新值，旧响应不得覆盖新值。只有确认未发送失败时才可明确回退；结果未知不能假装回退了真实壁纸。
- 没有当前目标或正在停止时，不自动开始播放、切换壁纸或把参数套到别的对象；保留安全的本地编辑或明确显示当前不可应用原因，具体交互在设计中给出。
- rc.44“下发未见效果”的相关revision误拒绝已离线复核并在[rc.45 Lucy粒子关闭/恢复短验](RC45_AUTHOR_REVISION_SHORT_TEST_20261021.md)中获得实际效果确认；这不等于全部作者参数通过，也尚未实现即时应用。即时应用仍是后续产品要求，不授权在日常rc.42上热改或把未确认命令自动重试；同轮身份、单执行器、有限期限和退出证明仍保留在内部实现。

## 反馈：控件状态优先，文字辅助

- 用户明确反对到处堆文字反馈。普通成功通过开关、数值、选中态及短暂完成标记表达，不在控件下常驻“尚未下发/草稿已保存”等解释段落，也不每点一次都弹成功通知。
- 处理过程中使用明确的控件忙碌状态；不能点时有足够的视觉区分。点击后不能毫无响应，禁用的按钮也不能看起来与可点击按钮相同。
- 错误就近呈现简短原因和可执行的恢复动作；错误详情、原始命令和诊断日志放在按需展开的详情中，不用大段报错挤占设置区。操作结果未知须如实提示，不能以绿色成功标记掩盖。
- 文字没有被全面禁止：图标仍须有清楚标签/悬停说明与无障碍名称，重要错误不能只用颜色表达。用户界面解释实际操作和结果，不暴露内部协议与调试术语。
- “已发送”不等于作者效果已验证；反馈文案与图形状态均不得把这两层混为一谈。

## 实施与验收边界

优先侧栏日常路径，独立窗作为可选扩展。保留已有单控制器、分级预览默认Everyone、同轮身份/清理门禁。侧栏与独立窗同一时刻只展示一个活动编辑入口；参数与状态共享，不重复发播放或属性命令。
