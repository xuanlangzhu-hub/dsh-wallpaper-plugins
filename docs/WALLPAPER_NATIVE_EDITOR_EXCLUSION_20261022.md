# 原生外观页与旧设置入口互斥：离线实现与复核

2026-10-22。接续[旧结构记录确认式处理](WALLPAPER_NATIVE_AUTHOR_STALE_RECOVERY_20261022.md)，本轮只处理编辑入口互斥，不扩展作者类型、制作候选或安装。日常保持DSH0.2.1-rc.2 / 外观rc.42 / Git Bash0.1.1。

## 结果和使用行为

开发源码新增共享编辑门禁，接到实际通用设置注册入口、原生页及主端独立窗状态。旧通用设置仍保留尚未迁入新侧栏的主题、强调色等选项。

- 打开旧通用设置时先取得编辑租约，撤下所有原生外观页的实际控件与作者视图，再挂载旧表单。原生标签页和宿主布局保留，显示简短占用提示；它们的浮动与会话副本同样暂停。顶栏入口此时禁用，悬停提示先关闭旧设置。
- 关闭旧通用设置后，保留的原生页恢复，读取同一控制器的实际值。这个切换不开始、停止或重启壁纸，也不下发作者参数。暂停时原生外观、播放、选项、筛选和选择等旧事件处理器拒绝写入，作者上下文失效，尚未完成的本地输入作废。
- 主端尚未收到第一条可信窗口状态时，不用初始`docked`值认定独立窗已关闭。窗口状态必须带本轮精确generation、已知mode及布尔清理字段；缺失或损坏撤销编辑权限，外代次事件忽略，状态流断开撤销证明。
- 若旧独立窗仍在，先通过原有认证`/api/main/dock`和原有窗口所有者关闭链处理；旧窗退出未确认时，两类主端编辑器均不开放。没有复用宿主同步close hook假装等待异步关闭，也没有绕过原Host身份或退出证明。
- 关闭反馈期限4秒。超时显示结果未确认，底层关闭物理操作尚未结束时不释放单通道，不因反复点击产生第二次关闭。迟到成功需新的明确点击才恢复编辑；旧通用页已退出时，该回包也不取得任何编辑权限。设置退出、服务重建与迟到结果的组合已补反例。

原生页自身的多会话/浮动副本继续共享原控制器和作者执行协调器，本轮互斥针对新原生入口与旧通用设置/旧独立窗，并未把宿主内部float改称Windows独立系统窗口。旧overlay组件仍为未注册的历史代码和QA入口，本轮没有重新注册或开放它；旧独立窗的新版UI迁移、弹出/吸附产品流程仍需另拆。

这里作废的是**切换时仍未完成的本地编辑**。此前已通过Enter或普通失焦完成的明确提交继续按既有执行器结算；互斥不撤回已发送命令，不在切换时重发、回退或自动重读作者参数。旧通用设置采用原表单，尚未等于UI重做完成。
