# rc.58 观感反馈：比例、通透背景与玻璃控件补修

## 2026-10-31 原包核验补注

后续核包发现：共享侧栏整体替换到固定rc.57会漏掉发行专属诊断导出包装；本报告的共享源码／材质检查不等于完整发行整合。首版候选已被拒绝，改在固定完整侧栏上应用本轮批准补丁；最终rc.59-b原包152项、实际包SDK16项均通过。以[最新候选与准备报告](RC59_UI_MATERIAL_CANDIDATE_AND_TRIAL_PREPARATION_20261031.md)为后续安装依据，旧失败证据保留。

用户 10 月 31 日反馈覆盖此前“等待观感”：rc.58 实际比例太小，字号缩小而控件比例失衡，整体拥挤；整栏毛玻璃遮住壁纸，应为可选项；玻璃质感应主要体现在控件，实际与设计稿有明显差距。本轮已完成源码补修及固定 rc.57 底座的 SDK 隔离验证，尚未打包／安装，日常仍保留昨晚恢复的 rc.57。

## 具体变更

1. **跟随宿主字号。** 去掉侧栏固定 `13px`，恢复继承宿主字体大小；普通说明从约 10–11px 恢复到宿主相对字号。实际 rc.3 SDK 中侧栏与父容器均为 16px。常用按钮约 36px、开关 40×24px、滑块手柄 18px；增加组间和行间留白，避免只放大按钮、缩小文字。
2. **侧栏背景独立可选。** 在“壁纸 → 界面透出”加入“侧栏背景：通透／毛玻璃”，默认通透。通透时整栏透明且 `backdrop-filter:none`；毛玻璃仅由显式选择启用。新字段 `panelMaterial` 为严格 `clear/frosted` 枚举，缺失／损坏旧值归一到 clear，保存到现有外观存储；不改变壁纸预设范围、背景模糊、全局玻璃强度或播放设置。
3. **玻璃材质用于控件。** 侧栏自己的按钮、分段选择、开关、输入框及滑轨采用半透明主题材料、克制的边缘高光和内阴影；开关与手柄独立绘制，不依赖系统默认外观。菜单采用更实的主题底色，配局部模糊，保留跨复杂画面的可读性。悬停、按下、焦点、禁用及系统强制颜色分支保留；未加动画、第三方控件依赖或新素材。
4. **较窄侧栏适配。** 280／320px 下界面选项纵向排布，较宽侧栏保持标签与控件横排；避免恢复正常字号后“跟随主题”等文字挤成两行。

仅修改两个既有实现文件：`src/sidebar/native-appearance-sidebar.js` 与同步生成的 `src/client.js`。client 生成片段之外只有两条加法声明：新字段默认值和合法枚举。原有 435 保护输入中 433 项保持，另外新增独立 QA 目录；版本、生产资产、原包／候选和其他类型开发成果保持。

## 设计对照与确认到的实现问题

通过 Pixso MCP 只读回读原画板 9:37 与状态板 9:412：原稿确实采用约 13px 字号、24px 整栏背景模糊。用户本次反馈优先于旧设计规格，不继续机械照搬这些数值；未修改 Pixso 画布。

SDK 检查发现新增分段选项放到壁纸页后，旧 `Choice` 组件的页面戳硬编码为 interface，点击会被拒绝。本轮只为内部调用增加默认仍为 interface 的 `choicePage` 参数，新材质控件显式绑定 wallpaper；会话／主题／编辑准入和可见性戳检查保持。修后实际 React 点击、存储和状态同步通过，未通过直接调用 setter 绕开 UI 证明。

播放状态实读原生右栏的七层祖先容器，均透明且无额外模糊；通透选项未被外层宿主底色盖住。未播放且没有背景时宿主使用主题底色是正常状态，不以此误判通透失败。
