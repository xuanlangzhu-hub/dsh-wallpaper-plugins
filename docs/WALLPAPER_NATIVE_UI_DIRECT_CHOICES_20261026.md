# 常用分段选择与配色色块

2026-10-26。接续[首次自动读取](WALLPAPER_NATIVE_AUTHOR_INITIAL_READ_20261026.md)，本步仅整理界面页四组常用选择：主题、强调色模式、文字可读性和深色配色。源码已提升，日常DSH0.2.1-rc.3／Whalerc.48／GitBash0.1.2保持；没有打包安装、操作DSH／WE或写运行设置，最终集中看整体观感。

## 交互变化

| Before | After | Why |
| --- | --- | --- |
| 鲸雾／鲸渊需展开列表再选 | 两个直接点选的分段项 | 两种主题可同时看见，少一次展开 |
| 跟随主题／自定义需展开列表 | 两项分段选择，保留既有自定义拾色器与hex值 | 模式与当前选中关系清楚，不改变自定义色的保存／重试规则 |
| 标准／增强文字需展开列表 | 两项分段选择 | 日常可读性调整直接可达 |
| 深海／石墨／暗紫／墨绿是文字下拉 | 四个具名的底色／强调色样本 | 颜色和名称同时可比较，不只靠颜色识别 |

沿用同一组选项值、controller API和错误／禁用投影。色块的八个颜色值与产品既有PALETTE_SWATCHES逐项核对一致，代表主题底色与其默认强调色，不声称是当前壁纸或自定义强调色的实时预览。鲸雾中仍不展示深色配色；切换主题后保留之前的配色。自定义强调色在切回“跟随主题”后仍保存，已有拾色、hex及失败重试控件保持。

分段使用原生radio和互斥name，容器有radiogroup及可访问名称。鼠标点选、方向键选择立即沿用原setter；Tab只进入每组的当前项，Space点已选项不重复保存。选中态有底色、边框、字重及✓；键盘焦点用focus-visible，鼠标不留下键盘焦点框。颜色样本外保留可读名称，强制颜色模式仍能看见选中和焦点；减少动态模式不做按压缩放。

在已保存主题与实际运行主题不一致时，点击已经选中的主题仍能显式重新应用，不重复写入相同偏好。DOM负例同时验证：隐藏控件或已卸载旧配色的遗留点击不能改新上下文。旧值缺失仍为不可用，不能静默选默认值；失败沿用真实保存值及就近错误，不以radio的瞬时勾选当成成功。

作者combo、播放策略及“更多外观”里的侧栏／画布／玻璃选项保留原菜单。后者属于下一步，未在本轮一起改名或重排。
