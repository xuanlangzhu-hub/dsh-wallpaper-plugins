# 基础控件回归：透明底与细边框

用户新决定覆盖此前玻璃路线：停止特殊组件／液态／薄玻璃探索，采用最初基础控件，普通背景透明，边缘一圈细框；后续重心为布局，底部分页留待单独调整。本轮已完成控件样式简化和固定底座 SDK 核对，没有打包或安装。

| Before | After | Why |
| --- | --- | --- |
| 普通按钮／搜索框的主题透色、渐变、滤镜和亮边 | 默认透明背景、1px主题细边框，无投影／背景模糊 | 按用户要求直接露出背景，取消塑料／外加装饰层观感 |

| 选中分段使用材质叠加 | 透明底、强调色边缘与原有勾选反馈 | 选中仍清楚，减少装饰 |
| 固定底部的分页整条背景 | 本轮不动 | 用户提出后续再改，避免把材质与布局混成一次改版 |

普通控件保留轻量悬停／按下反馈、focus-visible、禁用和错误状态；浮层菜单保持可读的主题底色，去掉额外玻璃层／投影。颜色选择器、图库内容图片／选中标记和各项业务逻辑没有为透明化而破坏。整栏原有「通透／毛玻璃」独立选项保留，默认通透；用户没有要求本轮删除此选项。
