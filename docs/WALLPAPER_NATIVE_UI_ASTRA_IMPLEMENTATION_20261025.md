| 顶部更换、关闭、状态与全宽按钮纵向堆放 | 两行对象／主控，单个主播放动作、低强调更换及更多入口 | 保留当前对象辨认，停止始终可达 |

| 界面十余项连续排列 | 主题与配色、文字与底色、更多外观 | 可读性／底色直达；深色配色与自定义颜色继续按条件显示 |

作者已读后的“重新读取”降低为文字入口，D1 的固定 18px 反馈槽继续保留。首次显式读取不变；没有把读取结构／本机记录冒称为实际壁纸值。恢复区、观察确认、清记录说明和资格围栏保持。

### 下拉交互与生命周期

控件保留可访问名称、当前值、展开状态、活动项、选中项和禁用项；没有重复可访问的原生 select。上下、Home／End、文字定位仅浏览；Enter 或点击确认，同值不重复提交。Escape 回到触发器；Tab／外部点击取消但不抢回焦点。

用浏览器顶层 popover 承载同一 DOM／主题范围内的列表，不使用全局 z-index 或 body 样式。默认向下，空间不足向上，列表限定在视口并内部滚动；一次仅展开一个。切分区、隐藏／卸载、目标／代次／主题／描述符改变均撤销旧选择。选择器点击不会让其它未完成作者输入意外 blur 下发；实际作者类型仍经原 controller 解码，false、0、"0" 等不混淆。自己的外部点击／焦点／可见性／滚动／resize 监听和 ResizeObserver 随展开收尾释放，没有轮询或新增超时放权。

## 分步实施边界

- D1：沿用已完成的反馈语义和粒子即时生效证据，本轮不重写事务控制器。
- D2／D3：完成壁纸层次与界面分组；正文独立滚动、固定主控及极矮窗口降级保留。
- D4a／D4b／D4c：依次整理控件表面、共享选择器及图库；候选内统一整合，但各次验证与修订证据独立留存。
- D5：完成当前安全元数据范围内的标签呈现。方案中可选的 schema／Host 契约扩展与首次自动只读加载没有混入；保留显式读取入口，不增加作者支持范围。
- D6：固定底座候选与代表预览完成；真实安装、浅深／自定义强调色／亮壁纸下的主观感受待用户方便时安排。

第一次准备复制误包含插件历史 `.tmp`，已核对命令身份后仅停止该自有复制进程；旧失败目录保留。排除 `.tmp` 后另开当前目录，无原始证据删除或 DSH／WE 操作。各运行日志／结果独立命名，不覆盖失败记录。
