## 最小反馈链

直接打开原生页，启动隔离Lucy状态，显式读取schema，随后只走文本字段：

1. 输入第一条文本并Enter，扣住作者执行IO。
2. 第一条未完成时输入第二条，保持本地编辑、不提交。
3. 释放第一条，等待该字段`aria-busy=false`，断言第二条仍在输入框且没有提前发送。
4. 第二次Enter后确认只发送最终第二条，执行峰值1、结束0。

分别核对无前置输入法事件、候选完成后普通失焦、额外延迟350ms释放。使用原3500ms断言期限，没有扩大等待或自动重试。

只读记录包含：文本input/focus/blur/keydown/keyup/composition事件，值、焦点、连接状态、禁用/错误/忙碌属性、父fieldset忙碌、页面可见性、alert；作者HTTP请求及响应头时间、底层IO进入/结算时间。浏览器与Node时间各自使用单调时钟，不跨时钟直接相减。响应头时间**不是完整响应体解析完成时间**；没有暴露内部协调器私有状态，因此仍不能仅凭该时间线判定所有内部阶段。
