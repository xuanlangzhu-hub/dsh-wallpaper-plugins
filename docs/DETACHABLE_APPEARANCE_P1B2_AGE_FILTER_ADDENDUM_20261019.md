# P1B-2增补：壁纸预览的年龄分级筛选

2026-10-19用户追加：像Wallpaper Engine一样提供三个年龄分级，允许选择性勾选；本机存在成人壁纸，不希望图库一打开就全部预览。该新增要求在候选/实机前完成，当前S1–S4补修保留，不能把补修通过当成新增筛选已经验收。

## 产品行为

- 图库提供三个独立复选项，对应WE的Everyone / Questionable / Mature，中文采用准确易懂的对应文案（所有人、含裸露/敏感内容、成人；核对实际WE术语后确定）。不自行编造12+/16+/18+数值阈值。
- 首次、缺失或损坏偏好时只开启Everyone；正常记住用户的筛选选择。三个全不选是合法空结果，不能回退成全选。两端同一权威偏好并同步，不放进每壁纸的四字段外观预设，不自动应用或重置主题。
- **在加载图片之前过滤**。未勾选类别不渲染预览卡片/详情图，不发缩略图或大图请求、不创建Blob URL、不预取或先加载后CSS隐藏/模糊。偏好尚未就绪时保持安全默认，不能短暂闪出所有图片。
- 收紧筛选立即取消对应在途请求、清除img src与缓存并撤销URL；旧选择/旧连接/旧筛选epoch的迟到结果不回写、不缓存。对S3的目录失效和生命周期修复一起考虑，但作为新增覆盖单独列证据。
- 分级缺失、空、类型错误或未知值必须归为unknown，不能当Everyone。不根据标题、文件名或模型猜分级；默认无图占位或折叠“未标注分级”区域，需要展示时由明确独立操作启用，不能搭便车随勾选Everyone自动显示。
- 若当前所选/正在播放项被新筛选隐藏，详情清除图片并提示“已被筛选隐藏”；不自动选择别项、不播放、不停止现有壁纸、不修改原WE或作者参数。不可由旧选中状态绕过预览筛选。

## 数据与接口

当前catalog仅公开id/title/type/availability/previewRef，尚未解析或公开分级。优先基于项目现有元数据加入白名单规范化分级；候选字段为`project.json.contentrating`与上述WE字符串，**实现时必须用可引用的公开项目/实际格式样例确认字段和值并写入交付，不把搜索摘要或这个候选名当成已验证契约**。本任务不授权读取展示用户成人图片，也不扫描日常库；离线夹具可以准确构造已确认格式。

Host将规范化rating及unknown公开为受限元数据，私有路径仍不外泄；主端cleanLibraryItem和两份快照保留该字段。不能只在companion自己过滤，让吸附窗或默认Lucy回退绕过。Lucy也须有明确可追溯的分级来源；缺少来源不能因为是播放已验证样例就自动视作分级已验证。

图片读取沿S2认证通道，Host用**当前权威筛选**及该条目分级判定是否允许；不信任浏览器自报rating/allowAdult、URL参数或只检查样式。被隐藏ID直接请求仍拒绝，且不进入图片字节读取。读取途中筛选收紧按S4同样使旧图片响应失效。现有认证、根目录/格式、并发、截止与实例隔离不得降低。

这是用户的本机浏览偏好，不是密码锁或家长控制，不更改Steam/WE账号内容偏好；元数据误标不能靠本功能保证自动识别。

## 定向验收与交付

只增加与本变更有关的有界检查，沿用已审监督器，不重跑无关长矩阵、不写无返回脚本：

1. 真实临时project.json→扫描→公开快照→两端筛选→认证图片路由闭环。三种正常分级、缺失/空/错误类型/未知值，元数据不含私有路径。
2. 首次Everyone-only、损坏偏好回退、三种独立组合/全不选、持久化恢复、主从同步；偏好加载前和切换中不闪图。
3. 对未勾选和unknown默认项统计前端fetch次数、Host实际图片读取次数、URL创建次数均为0。合法身份直接请求隐藏ID同样拒绝，不只截图看不到。
4. 已展示成人图→取消勾选；在途成人图→取消勾选→迟到回包；切换窗口/重连/刷新目录后不恢复被隐藏图。缓存和对象URL释放可计数，不人工补调用dispose代替真实筛选事件。
5. 最小隔离生产页面中，允许项使用可解码小图`naturalWidth>0`，隐藏项零请求；现有播放不被筛选动作启动/停止，四字段预设不受影响。
