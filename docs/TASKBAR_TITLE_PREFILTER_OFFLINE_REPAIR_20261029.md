# 任务栏身份检查：标题预筛离线补修（2026-10-29）

本轮完成一个最小补丁：在既有窗口枚举中，先用标题排除无关窗口，再进入原来的进程／标题／快照检查。仅隔离源码改变；没有安装、日常进程查询、窗口操作、COM、采集、发布、推送或清理。日常仍是 DSH0.2.1-rc.3／Whale rc.53／Git Bash0.1.2。

## 起点与假设

[rc.55实测](RC55_TASKBAR_STAGE_TIMING_SHORT_TEST_20261029.md)中，worker两次身份检查分别921.3161／886.4631ms，DeleteTab记录点差1.2624ms。M1没有把身份检查内部逐项计时，不能把0.9秒全部归因于ProcessName。

按优先级检验：无关窗口进程读取过多、重复枚举成本、其它身份检查步骤。本轮只改变第一项，保留后两项，使用调用次数而非替身耗时作反馈。实际任务栏闪现仍未解决，不能以本轮离线结果宣称加速多少毫秒。

## 固定输入与补丁

- 固定输入：`.tmp/taskbar-stage-timing-20261029-b/isolated/native-source/`，19项M1构建输入，逐文件SHA256见 [baseline.json](../dsh-whale-mist/qa/taskbar-title-prefilter/baseline.json)。
- 新输出：`.tmp/taskbar-title-prefilter-20261029-c/isolated/native-source/`。
- 仅 `SourceWindowHelper.cs` 的 `FindWindowsByTitle`、`FindProbeWindows` 各新增四行：注释、512字符缓冲、读取标题、Ordinal相等／前缀预筛。没有新增生产类、签名、配置或依赖；其余18输入保持原字节。
- **没有搬走原来的标题检查。** 候选仍按原流程读取进程名，随后再次读标题，再Inspect。预筛后若标题在读进程时改变，仍由原检查拒绝。进程名保留OrdinalIgnoreCase；标题保留Ordinal。
- 每次RealWindowProbe.Inspect仍有三轮新鲜枚举，保留同名歧义拒绝、HWND／PID／StartUtc复验、可见／最小化／cloaked事实、Job／父监督、首个发布帧、一次异步动作、停止与清理门禁。没有跨帧缓存、预热或owner／TOOLWINDOW／SW_HIDE改动。

可复现配方和QA：[taskbar-title-prefilter](../dsh-whale-mist/qa/taskbar-title-prefilter/README.md)。补丁与输入／输出指纹在输出的 `native.patch`、`source-receipt.json`。

## 真实调用链与底层IO替身

新夹具直接编译实际 `SourceWindowHelper` 和 `RealWindowProbe` 方法体：EnumWindows／GetWindowText／PID等底层读取替为内存数据，Process类型仅在QA副本中别名到夹具。全部DllImport均被移除；未允许的native入口一律抛错，并用ShowWindow、CreateProcess入口哨兵作负向验证。没有复制一份“理想筛选算法”来代替待测方法。

38项新检查覆盖：两个枚举入口、真实RealWindowProbe三轮枚举、进程名／标题大小写、PID0、死HWND、异常读取、cloaked差异、不可见／最小化事实、同名歧义、错误HWND／PID、StartUtc相差100ns／进程消失、扫描间新增重复／PID变化／关闭，以及进程读取期间标题变化。关闭路径覆盖稳定absent、同名ambiguous、PID变化拒绝；没有执行真实关闭或凭计时文件授权清理。

150组固定种子的稳定窗口集合，共301份序列化观测（含一个完整初始快照）在旧／新实现间完全一致。红组只在三项“无关进程读取应为0”的优化断言失败；绿组38项全通过。
