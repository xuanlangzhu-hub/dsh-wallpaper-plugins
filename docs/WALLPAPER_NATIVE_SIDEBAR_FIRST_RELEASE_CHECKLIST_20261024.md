## 结论

原21个持久化字段中，**20项已有原生入口，opaqueChat由聊天底色派生**；没有必须靠再加按钮才能补齐的普通字段。background通过关闭／启用与本地文件动作覆盖四种来源，并非一个可任意跳转的下拉框；跨来源须先明确关闭或移除，不隐式抢停旧源。

这只表示入口迁移覆盖，不表示整页UI、所有作者参数或Windows实机已经验收。下一步应进入独立候选源整合，不再机械增加低频动作。

### 持续保留的限制

普通appearance setter与预设恢复仍使用吞存储异常的既有persistSettings。正常存储和当前值已有证据，控件当前值／✓不单独保证故障时可跨重启持久化；首版不新增“全部保存成功”的承诺。若以可靠故障反馈为候选要求，应另补一项最小修复与负例，不能在清单里勾成已解决。

Lucy之外作者参数、MP4逐codec、所有主题组合、Windows焦点／最小化、长期表现和最终视觉尚未全面验收。首次断流根因、低优先级滚动A、三体源端变速仍保持原结论；历史15项缺QA EXE及旧超时不因本轮静态检查变绿。
