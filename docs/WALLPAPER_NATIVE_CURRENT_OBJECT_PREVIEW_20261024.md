## 变化

- 固定对象区的标题旁增加72×40.5px缩略图，沿用主题预览底色和已有Preview组件。不增加选择、播放、刷新按钮或成功提示；图片装饰性alt为空，名称仍由相邻标题提供。
- 播放对象身份明确时展示它的预览，即使用户另选了其它壁纸；停止且没有活动源时展示所选壁纸。活动身份冲突、损坏、等待中但没有明确源，或清理／门禁未知时不借用所选图片冒充当前源。缩略图是静态登记图片，不代表实际画面、实时采集帧或播放已成功。
- 从完整的已批准目录取对应行，不受图库搜索和分页影响。必须满足目录ready、勾选分级、支持类型、available和正确previewRef身份；未勾选分级、未知分级、损坏引用和不可用条目不请求当前对象图片。不信任外部previewUrl。
- 普通本地图片／视频继续走自己的文件名与操作，不拿WE所选海报作本地媒体预览。None保留已选WE对象的静态预览与原“启用”动作，不自动播放。
- 复用原预览reader、2并发队列、4秒期限与Blob URL所有权逻辑。固定对象区与图库实例各自拥有URL，沿用既有render先撤下旧消费者、passive cleanup再释放的修复；没有添加共享URL缓存、重试或延迟释放计时器。切到界面仍保留固定对象及其同一资源，真实tab隐藏／卸载会撤销所属图片和请求。

原图库测试中“选择后总活动URL为0”的旧假设按新增固定对象所有权改为：图库已撤下、固定对象已解码、总活动URL恰为1；真实收起／卸载仍必须为0。既有401／409精确错误门禁保持，没有允许新增Blob错误或预览HTTP错误。
