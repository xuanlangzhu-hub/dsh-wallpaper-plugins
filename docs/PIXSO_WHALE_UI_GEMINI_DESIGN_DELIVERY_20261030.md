## 5. 侧栏宽度 `280px–520px` 响应式适配说明

1. **常规宽度 (`360px–420px`，画板基准 `400px`)**：
   - `PlaybackHeader` 单行排布（左：`52×30` 缩略图 + 标题/状态；右：主按钮 + 次按钮 + `⋯`）。
   - 滑块轨道宽度自适应 `120px–140px`，右侧固定 `46px` 数值框 + `18px` 反馈槽。
   - 图库采用 2 列 `16:9` 网格（`grid-template-columns: repeat(2, minmax(0, 1fr))`，间距 `12px`）。
2. **窄栏宽度 (`280px–340px`)**：
   - **标题省略与动作换行**：`PlaybackHeader` 允许 `flex-wrap: wrap`；壁纸标题设置 `min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap`，当右侧同时出现 `播放` + `停止` + `壁纸参数` 三个按钮时，操作组自动折至第二行右对齐，不挤压左侧缩略图。
   - **字段行防挤压**：普通设置行左标签允许折行（`overflow-wrap: anywhere`），右侧滑块轨道最小缩至 `72px`；`更多外观` 中的两段式分段按钮最小宽度缩至 `128px`。
   - **图库列数自适应**：当侧栏内容区净宽 `< 300px` 时，图库网格由 2 列自动回退为 1 列单卡全宽展示，避免卡片标题截断只剩 1–2 个字。
3. **宽栏宽度 (`440px–520px`)**：
   - 字段行保持左右两端对齐，滑块轨道随容器弹性伸展（最大不超过 `220px`）；图库在净宽 `>= 460px` 时可保持宽裕 2 列或自适应 3 列（`repeat(auto-fill, minmax(140px, 1fr))`）。
4. **浮层防裁切与底部翻页条**：
   - 自绘 `Select` 列表 (`[data-whale-choice-list]`) 与 `ActionMenu` 弹层保持现有源码的视口边界夹紧逻辑（水平限制在 `[owner.left + 8, owner.right - 8]`，垂直根据下方剩余空间 `< 160px` 自动向上翻转展开）。
   - 图库底部翻页条 (`< 1 / 3 >`) 采用 `position: sticky; bottom: 0` 吸底，带 `#0B0E17CC` 半透明磨砂底衬，防止滚动长图库时迷失页码。
