## 实现约定

### 1. 原生调度与参数

正式 helper 增加 `--taskbar-hide`，只允许 `pipe + --owned-location`。预览保持原时限，日常保持 `--forever`；不带新开关的合法诊断 argv 保持原行为。拒绝重复、缺值、错位或与非 pipe 模式混用，不能静默忽略未知参数。

Host 默认在 WE 播放中传新开关，提供 Host 环境回退 `WM_WALLPAPER_TASKBAR_HIDE=0`；关闭时不调度 worker，保留屏幕外播放。回退不是前端可传的原生命令，也不更改系统/WE 配置。本轮不新增复杂设置面板或持久化迁移。

保留至少 10 秒的有效发布基线，之后满足身份与停止门禁才调度一次，枚举/进程启动/等待/COM 都不在帧循环里等待。停止早于触发时零次执行。每次开始/重新开始是新 location、新调度状态，旧轮不能作用于新轮。

正式原生代码不得依赖安装包里不存在的 QA 路径。可把已验证的最小 worker/身份逻辑抽为原生项目和 QA 共用文件；只调整 QA 的编译引用接线，不重写已审查的策略。避免复制成两套各自漂移的 COM 实现，也不要把整个 QA 自检或生成构建器塞进生产包。

### 2. 身份与动作边界

以本轮 HWND、精确 location、PID、进程 StartTime 作为身份，复核 wallpaper64 和可见/未最小化/未 cloaked 状态。开始时锁定身份，不能每次重新采集新身份来“通过”PID/HWND 复用检查。调用前及 HrInit 后重新检查身份与停止状态。

仅一次 HrInit/DeleteTab，不 AddTab、不重试其它隐藏路线、不改 owner/窗口样式、不隐藏/激活窗口或重启 Explorer。原 WE 进程可能同时承载桌面和本轮源，不能结束该进程。清理同样限定本轮身份，发现替换目标就保留未确认状态。

### 3. 收尾是本轮必须先做的改动

定义一个受控收尾顺序：标记停止并取消待执行动作 → 向在飞 worker 传播停止 → 有界等待，必要时终止并确认 worker 退出 → 关闭/确认本轮源 → 释放 Host 所有权，允许下一轮。

不得保留现有“2.5 秒杀采集，同时关源”的旁路。也不能仅把 2.5 秒改成更大数字就声称完成：采集父进程强退时，worker 仍需受监督；工作进程被启动到监督建立之间不能存在可以迟到执行 Shell 动作的空档。可以采用原生进程容器或等效受控机制，但必须有实际假进程回归证明父丢失时没有仍在运行/迟到执行的 worker。

正常停止尽快取消，不为了等 30 秒动作期限拖住用户。现有原生边界含帧读写最长 5 秒、策略 settle 最长 10 秒、关闭源最长 15 秒；统一核算总停止期限并记录预算，最外层不超过 35 秒，检查用可控时钟/假进程，不真实 sleep 35 秒。强退是最后兜底，且仍要核验 worker 已结束；无法确认时保留 cleanup=false/未确认所有权，拒绝新一轮，提供停止重试。

正常停止、预览到期、源丢失、stdin EOF/Host 断开、捕获初始化/发布异常、重启、切换来源、插件停用/宿主退出都走同一门禁。只选另一张壁纸仍不切换/创建新源；实际重新开始须先确认旧轮清理。

生产日常与生产预览均不读取其它应用中的 Esc 来停止播放或杀 worker；Esc 只保留在独立受监督 QA，避免把 QA 的停止回调原封不动搬入正式 runtime。

### 4. 失败与状态

隐藏动作失败且 worker 已确认退出，播放继续，记录警告，不让 `level:error` 误触发 Host 停播。失败不改选中的壁纸、主题、窗口属性，不重建捕获或尝试第二种隐藏策略。

状态至少区分 disabled/waiting/pending/succeeded/failed，以及单次 attempted、worker started/exited/cleanupSafe、HrInit/DeleteTab 结果、停止原因。调度不等于进程启动；未执行/未知值仍为 null。调用成功只记 API 成功，不写自动确认“任务栏/Alt-Tab 已隐藏”。

保留 F1–F3：完成前采集但完成后发布的旧帧不能被列为 postActionFrame；触发/完成/帧使用明确的同一时间原点；启动事实经实际启动回调记录。不要靠增加缓冲帧或丢旧帧掩盖证据问题。

capture stdout 仍只有 WHL1 帧协议。状态走已有结构化 stderr/每轮有界报告，不能每帧无限追加进程状态日志。若需要在现有播放状态处显示警告，只添加简短中文状态，不重排列表、按钮或主题 CSS。

## 后台验收

检查实际正式 Host 和本轮正式 helper 入口，不能只再跑一次独立 QA 自检当成接入已完成：

1. Host 真实 spawn 参数：预览/日常/回退三种形态；对应候选 `--parse-check` 通过，错误混用拒绝。旧 bin 和包内旧 helper 的检查不能冒充候选结果。
2. 正式帧入口：未发布/未满 10 秒不触发；在飞时多帧继续；每轮一次；旧队列帧与完成后新采集帧分别归类，覆盖初始化时间偏移。
3. 身份变化/已停止/不可见拒绝；启动前取消不创建 worker；pending 期间启动事实为未知，真正启动后才改 true。
4. HrInit/DeleteTab 失败、坏 worker 协议、超时：有界退出；确认退出的隐藏失败为警告且继续采集；退出未确认阻断关闭/下一轮。
5. **跨 JS/native 真实接缝**：Host 停止时 fake worker 阻塞，确认不会先调用关闭源；正常退出/强退/父断开均确认 worker 不存活、不留迟到动作，未确认时不冒充清理成功。
6. 源初始化失败、帧发布异常、预览到期、重新开始/换壁纸、来源切无、停用/退出、停止重试各自清理一次且只操作本轮。覆盖先停止后迟到窗口/worker 的现有回归。
7. 前端现有选择和自动播放取消回归保留，普通成功诊断/warn 不误判为播放失败。日常模式无 QA 时限或 Esc 行为。

针对改动跑 `npm run check`、`npm run test:wallpaper-host`、`npm run test:sdk-contract`；涉及 client 时增加 selection/既有 wallpaper 外观相关回归，不扩大截图或重测其它主题。保留原 QA 109/19/5 边界检查；若共用文件提取影响 QA，复跑并使用新输出，不覆盖原结果。
