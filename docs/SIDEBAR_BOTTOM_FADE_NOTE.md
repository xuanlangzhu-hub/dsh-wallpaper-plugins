# 侧栏透明后，账号上方出现矩形暗带

日期：2026-10-07。用户提供截图，箭头指向工作区列表底部、头像/用户名上方的一条暗带。**可见现象成立；最吻合的代码来源是官方列表底部渐变，不是新增弹窗。实际截图对应节点尚未用 live DOM 确认，不能把推断写成已修复。** 本轮只读源码，没有操作 DSH 或 Profile。

## 只读发现

从当前官方 `app.asar` 只读提取的 `@deepseek-ai/dsh-client-ui-workspace/lib/client.js`：分组列表、平铺列表、搜索列表都会渲染 `span._9lTDKa_fade`。其样式为：

```css
._9lTDKa_fade {
  left: 0;
  right: var(--dsh-session-list-edge-inset);
  background: linear-gradient(to bottom, transparent, var(--dsw-specific-sidebar-fill));
  pointer-events: none;
  height: 24px;
  position: absolute;
  bottom: 0;
}
```

它绘制颜色，不是对项目文字做 alpha mask。透明壁纸态把 sidebar-fill 设成带 alpha 的颜色；额外再叠一条这样的渐变，会使底部更暗，形成矩形边界，与截图位置/形态吻合。侧栏外列与内部 root 也各自使用 sidebar-fill，不能用只有一个空侧栏的夹具证明真实底部外观。

官方侧栏壳的 `footArea` 自身没有背景声明；不能仅凭头像旁边的位置认定是账号弹窗。用户截图中的方框与本 fade 的对应关系仍须通过完整侧栏夹具/短实机验证；不能排除壁纸画面或其它层的贡献。

证据：`F:\deepseekharness\.tmp\sidebar-bottom-readonly-20261007-195012`，包括官方侧栏/工作区/账号 CSS 与代码只读副本。没有修改官方安装包、源资产、日常数据或壁纸。
