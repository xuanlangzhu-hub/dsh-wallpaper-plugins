`multiple`未设true的页通常按page地址复用，但实现会结合pane寻找已有内容，不能把它当作整个窗口甚至所有会话的唯一编辑器锁。页签可能在不同会话、pane中存在；Whale仍须在控制器/租约层保证单活动编辑入口。宿主页签是会话范围，Whale壁纸/外观控制器则共享，不能每挂一个Body就创建第二份播放器、桥接注册或属性执行器。

宿主有dock/float与窄屏fullscreen模式。这不证明float就是Windows独立系统窗口，也不保证窄窗口始终能并排显示聊天。现有Edge伴随窗的身份、访客隔离和关闭证明继续独立保留；不能用宿主内部float替代用户要求的独立系统窗而不说明。

插件开发manifest当前未声明右侧栏依赖，旧日常归档也不能据此假设已具备注册代码。未来隔离原型/独立候选须补实际0.2.1-rc.2的客户端加载依赖与服务注入、装载顺序检查；不要只写一个新`ctx`字段就声称SDK支持已经接通，也不要热改冻结manifest。

## 内容层级草案

这是后续布局约束，尚非已实现UI。建议一个“Whale 外观”页，内部只有“壁纸 / 界面”两个常用分区；不要再套多层导航或首屏铺满全部高级功能。

| 区域 | 默认内容 | 二级或按需内容 |
| --- | --- | --- |
| 壁纸顶部 | 当前壁纸小预览、可读标题；一个“更换”入口；清楚区分所选与正在播放对象 | 完整路径、ID、来源信息进入详情；非Everyone内容按既有分级门禁，不先加载缩略图再遮挡 |
| 壁纸控制 | 一个固定可达的播放/停止主控；繁忙时对应状态与防重入反馈 | 播放模式、随DSH启动自动播放收入“播放选项”，自动资格仍只有Lucy，不随类型支持扩大 |
| 当前壁纸详情 | 有效作者参数按作者分组呈现；后续开关改即应用、滑块有界合并 | 不支持项省略或用简短分组说明；恢复作者默认值在菜单中带范围确认，不占主操作行 |
| 壁纸画面 | 亮度、遮罩；需要时展开模糊 | 手动外观预设另设管理入口，不与作者默认值混用 |
| 更换壁纸 | 独立图库视图：搜索、Everyone/Questionable/Mature筛选、预览卡片；保留返回当前壁纸入口 | 扫描刷新放图标按钮/菜单；选择新项不自动发送作者参数，不暗中覆盖正在播放对象 |
| 界面 | 主题/配色、界面不透明度、文字可读性、聊天底色 | 自定义强调色按模式展开；不出现作者参数或播放器诊断 |
| 故障恢复 | 发生错误时，就近出现短原因和必要动作 | 原始错误、日志、重试清理等按需展开；正常首屏不展示常驻调试状态或未接入占位控件 |

播放主控与当前对象应在长参数列表下仍可达；内容区单独滚动、标题可截断并有完整名称提示。具体宽度交给宿主，后续覆盖约360/520px内容宽度、长标题、空图库、无作者设置和很多字段，避免依赖一个固定宽度。主操作不以三颗“草稿”按钮占据常用区。

主题使用宿主公开颜色变量和已有Whale设置；原生承载不代表半透明自动正确。需检查宿主pane/dock背景和Whale局部背景的叠加，限制样式在Whale正文，不能覆盖其它页、输入框或整个dock来制造透明效果。实际透明度/亮背景文字对比要留到受控候选验收，静态变量名不算视觉通过。

## 交互与状态约束

1. 正常路径：点顶栏Whale入口 → 打开/定位自身原生页签 → 看当前壁纸 → 调整参数。关闭设置页仅释放视图订阅，**不停止当前壁纸**；切换会话或重新挂载也不重复播放/属性命令。
2. 选中壁纸与正在播放壁纸分清。编辑目标不匹配时不得默默下发到其它源。没有目标或正在停止时不自动开播；未播放时可保留本地值，但不能显示“已应用”。
3. 后续即时下发单独实施：开关即时显示处理中；滑块在提交点合并最终值；相同目标的更新序列化或合并，旧结果不覆盖新输入。复用原单执行器、schema/身份/代次、期限和未知结果门禁。rc.45修复不能被UI重构绕过。
4. 普通成功以控件状态和短暂完成标记表达，不每次弹Toast，不常驻“草稿已保存”段落。只确认发送时不显示“效果已验证”。确定未发送失败与发送结果未知分别呈现，不自动重发未知命令；错误以简短文字加图形就近表达，有无障碍标签。
5. 独立窗后续迁移另拆：打开成功并确认新编辑入口可用后收起/移除本页内容；失败保留原入口。吸附先恢复原生页，再确认独立窗退出并完成租约交接。不能清空其它侧栏页签或简单toggle整个右栏；也不能在async close handler中忽略Promise后宣称关闭完成。

## 第一步交付与验收：只读接缝原型

在隔离副本以固定rc.45代码（包含已复核的作者revision修复）为后续整合参考，保持既有单controller；原型不生成版本号或生产assets，也不进入安装。

- 注册独有类型，例如id=`dsh-whale-mist/appearance-sidebar`、kind=`whale-appearance`（拟定名称，非宿主既有类型），正文/标题两槽使用同一id，所有注册有释放函数。
- 顶栏现有Whale入口通过服务打开该类型；只有原型中替换原打开动作。没有服务或活动会话时有界失败，不能回落成第二个overlay。不要更改官方右栏开关。
- 正文只显示“当前壁纸/播放状态”和现有亮度的只读数值，订阅既有controller；不显示尚未接入的可点按钮，不下发播放、停止、属性或弹窗命令。第一步先证明承载，暂不称完成整个UI改版。
- 离线覆盖：类型与key匹配；打开不覆盖其它种类；重复点击不无界新增；无会话拒绝；多个页/会话仍用同一controller；mount/unmount/隐藏/恢复不产生壁纸命令；卸载释放类型、槽位及订阅；旧异步结果不能回写新页。
- 明确标记测试层次：实际SDK服务/槽注册代码与底层模拟IO分开。mock服务调用通过不等于真实右栏渲染通过。单阶段/总超时和外层监督、所属子进程退出记录遵循AGENTS；没有真实进程时写明0。
