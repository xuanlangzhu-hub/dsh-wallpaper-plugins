## 方向

现版控件依赖渐变高光和投影，视觉上偏拟物凸起。后续减弱这部分，分别比较以透色／局部模糊为主的轻磨砂材质，以及少量边缘折射的玻璃材质。用户尚未指定必须采用 Apple Liquid Glass，不擅自把液态折射当作唯一目标。

保留用户已确认的原则：面板默认通透、毛玻璃可选；重点是控件材质；字号跟随宿主，交互逻辑保持。先用同一背景和同组按钮／开关／滑块做独立离线对照，确认材质方向后再接回插件；不继续盲调生产侧栏或生成新候选。

1. **rdev/liquid-glass-react**
   - 源码：https://github.com/rdev/liquid-glass-react
   - 作者演示：https://liquid-glass.maxrovensky.com/
   - 仓库列为 MIT；作者说明提供可调磨砂、边缘折射、高光、交互效果。演示页面可访问，包含模糊、折射强度等参数。
   - README 标注 Safari／Firefox 的位移效果受限；尚未在本项目 Electron 上验证。未将演示默认强度等同于适合壁纸控件的最终参数。
2. **sohumsuthar/liquid-glass**
   - 源码：https://github.com/sohumsuthar/liquid-glass
   - 仓库列为 MIT，提供分层 HTML／CSS 和可选 React 用法，说明了 regular／clear 材质及 SVG 折射。
   - 作者演示链接本次抓取失败；未宣称已看过其动态效果。作者的性能和物理准确性描述未经本项目独立验证，仅列为技术参考，不直接选为依赖。
