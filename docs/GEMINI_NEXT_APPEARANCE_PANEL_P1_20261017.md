## 入口和布局

- 会话顶栏新增小按钮，中文“鲸系外观”、英文“Whale appearance”，可用紧凑图标但须有可识别标签/tooltip。`aria-expanded`及`aria-controls`反映唯一面板状态；重复点击切换显示，不新增实例。窄顶栏不能挤掉官方操作。
- 默认右侧小面板，目标宽约360px，实际限制为视口减去两侧留白；上方避开原生顶栏，最大高度限制在视口内。面板内部滚动，标题/关闭和播放状态/停止操作保持可达；320px窄视口仍不横向溢出，不能因折叠把停止藏到无法访问的位置。
- 没有全屏遮罩、背景变暗/模糊、`inert`、body滚动锁或焦点陷阱。采用有名称的region/非模态语义，不复用原生`showModal`或`aria-modal=true`。面板以外继续点击、选字、输入和滚动；外层覆盖容器不截获整窗鼠标。
- 面板本体使用可靠的不透明主题底色，跟随Mist/Abyss/配色，自己的文字/操作不能因调低surface或高亮壁纸而消失。不得改变输入卡片、桌宠、会话背景裁剪或官方右栏布局。
- 固定可见关闭按钮。打开可聚焦面板标题；关闭尽量还给原触发按钮，按钮已卸载时安全降级。Escape只在面板持有焦点且没有更上层原生/官方弹层接管时关闭，不吞掉主会话、颜色选择器或其它弹窗的Escape。
- 新面板不能盖住官方设置/审批/问题弹窗，不能用极大z-index压过所有层。沿用根overlay的实际层叠，隔离验证模态/菜单共存。
- 首版不做拖拽/缩放/停靠位置持久化、额外快捷键体系或动画重构；完成一键入口和即时调节优先。面板开关/当前分组只作会话内UI状态，重开DSH默认关闭，不新增存储格式。

用“画面 / 界面 / 壁纸”三组或等价清晰分区，复用真实控件，不把原长表原样挤进窄卡片：

| 界面 | 主题、深色配色、跟随/自定义强调色、文字标准/增强、聊天底色0–100、侧栏底色与原层次/玻璃选项 |
| 壁纸 | 现有有界名称列表/显式刷新、所选与实际播放区别、模式/自动播放偏好、开始/重新开始/停止及失败原因 |

现有图片/视频导入与移除可复用原控件，保留文件/大小/类型/存储校验，不新建不同媒体实现。本步不增加缩略图、收藏、搜索服务、作者WE属性或新主题字段。现有全局reset及提示保持，不能把关闭面板当reset。

打开/关闭/分组切换不启动、停止、重启播放，不重建stream/canvas、不清预设、不改source/scene/mode/auto-start、不中断用户输入。壁纸列表只在用户进入相应分区时按需读取，已有确认可复用；外观调节不触发refresh/扫描、窗口枚举或新轮播放。切换背景/全局reset等本来会停止的明确操作仍保持原契约。

## 必须先完成的状态复用

当前`WhaleAppearanceSettings`以`useState(() => controller.read())`保存本地副本，只有触发它自己的回调才setSettings；`controller.read()`又每次返回新对象。**直接复制组件，或把read直接当useSyncExternalStore的getSnapshot，均不可接受**：前者两入口互相陈旧，后者可能无限更新。

1. 在唯一controller中增加稳定的设置快照/订阅（如`getSettingsSnapshot`与`subscribeSettings`），保留旧read的防御副本契约。未变时快照引用稳定，接纳合法变更时创建新不可变快照；订阅可退订、卸载清理。不要靠定时轮询、DOM抓值或同文档不会触发的storage事件同步。
2. 所有设置变更统一发布：set（含opaqueChat/chatBackdrop迁移映射）、reset、预设apply、成功媒体导入等。归一化、原存储、CSS投影与主题/backdrop更新仍走既有入口，不因两个消费者重复写入、重投影或产生反馈环。非法值拒绝后状态保持。
3. 原通用设置与新面板读同一快照，拆出可复用字段/分组，避免复制整份设置逻辑、文案与校验。A入口改值，B入口无需重挂载就收到；preset apply/reset同样同步。按钮busy/播放状态使用同一权威状态，不以某个组件本地布尔代替全局动作门禁。
4. 库确认仍归engine所有，保留R2。两个设置视图同时挂载/刷新时不能相互恢复陈旧确认；共享读取不能因一侧卸载而让另一侧得到错误的可用结论。用现有revision/取消屏障并补必要的快照通知/协调，不把组件可见列表当授权，不新增目录轮询。
5. 面板只管理可见性。跨会话切换/触发按钮卸载不会销毁播放controller；重复打开仍单例。插件停用时移除入口、宿主、订阅、键盘事件和UI状态，沿用既有唯一播放清理，不新增第二次stop或让旧异步结果重新挂面板。

保持rc.34存储键、默认值/范围、主题兼容、A1/A2修复和四字段预设v1不变；不新增“预设自动应用”或保存主题字段。R1停止归属/cleanupPending、R2目录确认与失败/取消保护必须保留。
