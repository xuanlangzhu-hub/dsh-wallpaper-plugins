# 图库密度、分页与状态标记

2026-10-26。接续[低频选项整理](WALLPAPER_NATIVE_UI_LOW_FREQUENCY_20261026.md)，本步完成图库呈现与入口整理。日常仍为DSH0.2.1-rc.3／Whalerc.48／GitBash0.1.2；未打包安装、操作DSH／WE或写运行设置，最终集中看整体效果。

## 变化

| Before | After | Why |
| --- | --- | --- |
| 卡片常为两列，标题两行，类型另占一行 | 480px起三列、普通宽度两列、299px及以下一列；标题一行省略、类型角标 | 一屏可比较更多对象，全名保留在title和可访问名称中 |
| 分页在长列表末尾 | 页码及前后按钮停留在可见底部 | 不用先滚到列表末尾；滚到底时最后一排仍能完整到达分页条上方 |
| 选中勾号与播放文字都混在元信息中 | 选中为边框／底色／标题旁✓，播放为缩略图右上▶ | 当前播放源与下次选中对象可以分别辨认 |
| 图库又出现“当前壁纸／更换壁纸”一行 | 顶部原“更换”直接变为“返回” | 减少重复标题和返回入口，aria-expanded表达展开状态 |
| “界面”页点更换只改变图库状态，仍留在原页 | 进入／返回都导航到壁纸页 | 按钮动作有可见结果；指针先打开与后续click不会误执行两次 |

每页仍最多12张，未增加预览并发或扫描范围。保留16:9预览、按需加载、全年龄／敏感／成人三项、空分级不回退、搜索先按分级过滤、不可用项禁用及原选择写入。卡片描述为普通隐藏文本，读屏可辨类型／不可用／已选中／正在播放，未渲染作者HTML。

播放标记只在现有状态报告playing、非playBusy且activeId等于该卡片时显示。选中其它项只保存weScene，不停止或替换当前源；停止、连接／等待、清理中及未知状态不能因为残留activeId就标成正在播放。该标记是现有状态投影，不是新增加的实时帧或原生进程验收。

底部分页使用主题实色小表面，防止下面的卡片标题透上来；它与当前16px面板内边距配套，贴齐可见底边。只在多页时出现，前后按钮保留无障碍名称／禁用边界及页码。正文侧栏仍沿用现有透明度，没有顺手修改整个侧栏或标题栏。
