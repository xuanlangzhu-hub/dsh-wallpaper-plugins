## 改动与实际含义

| Before | After | Why |
| --- | --- | --- |
| 作者 bool 初始以 indeterminate 减号覆盖参考值 | 显示实际记录的 true／false，来源由独立说明表达 | 不把未知可信度误画成第三种布尔值；仍没有读取 WE 实际属性 |
| 各类字段零散插入处理中／✓，出现时可能挤动控件 | 五类字段统一 18px 固定反馈槽：参考值、处理中、下发确认、失败、未知 | 值与送达状态分开，处理中／成功无需常驻段落 |
| error／unknown 都可能把表单标为 aria-invalid | 只有本地数值／文字／色值校验错误保留 aria-invalid；命令失败／未知使用字段描述和原有组内提示 | 操作结果未知不是输入值格式错误 |
| unknown 说明容易被理解为具体字段已经发送 | 使用“本轮修改结果未确认”，bool 的悬停说明同步采用该含义 | 未发出的排队字段也可能共享保守 unknown，不伪造逐字段发送账本 |
| 初始来源常驻正文，读按钮叫“刷新设置” | 可点击、可键盘展开的“数值来源”；按钮“重新读取”，编辑中为“取消编辑并重新读取” | 明确只读取设置结构和本机记录，不读取壁纸实际值、不重复下发 |

下发确认继续显示小号✓，可访问描述为“下发已确认，效果请观察”；不变成“画面已同步”。状态槽空时保留默认值／本机记录描述，不由 Host 的历史 confirmed 重建本视图✓。重新读取后仍显示记录值，但本轮确认标记清除。

RGB 三个子滑块共享颜色字段的一个反馈槽；滑块附带数值输入共享父字段的描述。颜色、数值和文字各自的格式错误仍就近显示。bool 的可访问名称保持字段名，送达状态通过描述关联，避免读屏把整段来源说明并入开关名称。

说明折叠采用现有 details／summary，样式限定 Whale 根节点，沿用主题 token 和字体。未加定时器、动画、依赖、轮询或自动读取。旧恢复区、观察确认、清记录和 pending 阻塞保持原样，没有新增重试／回滚。
