## 长跑性能与边界

最终 Native 42934 帧、内容变化计数 42381；客户端已绘制 40243 帧，客户端计时 2120.504 秒；最大已观察解码错误为 0。全段采集均值约 20.2 fps，绘制均值约 19.0 fps，**含页面隐藏期及重复画面，不能称为独立动画帧率或可见稳态帧率**。报告累计平均延迟约 94.8ms，没有独立端到端光学延迟测量。

Native 32 个不少于 30 秒的资源区间样本，按 32 个逻辑处理器归一化的 CPU 均值约 0.136%、区间最大约 0.446%；工作集范围 88.0–133.8 MiB。以上不是单核百分比。DSH 家族包括当时发现的子进程及采集辅助程序，不能再把采集内存重复相加。采样期间没有持续增长趋势，但一次 35 分钟不能证明长期不会泄漏。

GPU 五个点位可取得：共享 WE PID 的**最大单个引擎**约 84.8%、95.4%、89.3%、87.4%、90.2%；采集 PID 的最大单引擎约 1.6–4.4%。这些涉及不同 GPU/引擎，**不能相加成为总 GPU 占用**。WE 同时包含原桌面壁纸和独立源窗口；GPU 查询仅覆盖固定角色 PID，DSH 主进程没有匹配计数且未覆盖全部 renderer 子进程，因此不能据此归因插件增量或宣称整应用开销低。

后续性能验证应做「原桌面单独运行 / 内部壁纸开启」的同环境对照并覆盖实际 DSH renderer；不擅自修改用户 WE 全局帧率/暂停规则。当前稳定性结论保留，高引擎占用作为待对照事项。

原报告有一次 `preview-status.json` 瞬时读取失败，缓存/后续读取恢复，没有超过宽限时间，不是解码失败。数据和解释见 `long-run/daily-sample-result.json`、`long-run-milestone-summary.json`、`long-run-resource-summary.json`、`gpu-summary-compact.json`。
