# 给小G：按壁纸保存外观预设P1（手动保存、应用、删除）

2026-10-16。先读`AGENTS.md`、`NEXT_TASK.md`、[当前状态](PROJECT_STATUS.md)、[120%补修复审](APPEARANCE_BRIGHTNESS_120_REPAIR_REVIEW_20261016.md)。用户已要求继续下一步：**不为120%这处参数调整单独打候选或再跑实机，随下一次功能包交付；日常rc.31保持。**

本次实现按壁纸保存外观的第一小步，完成后交Codex复审。目标是用户调好一张壁纸后，能明确保存、重新应用或删除这张壁纸的一份设置，避免每次重新拖滑块。

## 本步产品范围

- 仅Wallpaper Engine已登记scene/Lucy，一张壁纸一份预设，无命名多套、导入导出或独立选择器。
- 只保存四项：`brightness`（20–120）、`mask`（0–90）、`blur`（0–24）、`surface`（40–100）。复用现有整数/有限数校验与投影，默认仍70/45/0/82。
- 在现有WE外观设置附近加一个小区域，显示预设归属壁纸标题及状态，提供“保存当前外观”“应用已保存外观”“删除预设”。中文/英文齐全，按钮键盘可用，沿用现有样式，不重排整页。
- **本步只有用户点击才保存/应用/删除**。选择列表项、刷新目录、开始/重开/停止播放、重载插件均不自动应用预设；UI简短说明“手动应用到当前外观”。自动随播放切换以后单独接入。
- 不保存theme/palette、区域底色、自动播放、播放模式、壁纸选择、媒体blob等其它字段；不接WE作者参数或修改原壁纸配置。主题/配色等更完整适配留后续。

## 归属必须清楚

预设按稳定scene ID归属，沿用现有合法ID规则（`lucy`及Host目录ID），不能按标题、列表下标、路径或窗口/PID命名。只操作当前可用的已选scene，未知/不可用项禁用按钮并保留既有原因提示。

现有`settings.weScene`是下一张已选项，`wallpaperStatus.host.activeSceneId`才是Host确认的播放项。请按以下边界实现，不借此改播放流程：

| 状态 | 预设按钮行为 |
| --- | --- |
| 已停止/idle且没有待清理播放 | 可编辑已选壁纸预设；清楚标“所选壁纸”，应用只调整现有四个外观值，不开源 |
| 稳定播放中，Host确认播放ID与已选ID一致 | 可保存/应用/删除该ID的预设，调外观不重启当前播放 |
| 正在播放A但已选B | 按钮禁用，提示“请先停止当前播放或切换到所选壁纸”；不将A的外观误存给B |
| 启动/连接/切换/停止中、waiting、清理失败或播放身份未知 | 按钮禁用；不猜测归属，不新增轮询或窗口查询 |

复用现有运行状态与目录快照。异步结果需绑定操作时目标和实例寿命，列表选择改变、reset或dispose后不能让旧操作套到新目标。不要为预设绕过Host的scene可用性或自动播放验证名单。

## 数据及操作语义

建议使用单独本地键`dsh-whale-mist.wallpaper-appearance-presets.v1`，结构如`{version:1, entries:{sceneId:{brightness,mask,blur,surface}}}`。现有`dsh-whale-mist.appearance.v1`继续保存当前外观，旧用户没有新键时预设为空，原外观保持，不迁移/复制成一库默认预设。

- **保存**：将当前四项保存到明确的目标ID，覆盖该ID已有的一份。其它ID不变，不改变当前外观或播放状态。
- **应用**：将该ID已保存的四项作为一次外观更新，复用既有归一化/持久化/投影和媒体update逻辑；所有其它设置不变。没有预设时禁用，不能用默认值伪装成已保存内容。不得因此重载图片/视频或重启WE。
- **删除**：只删该ID记录，不改变当前画面四项值、不重置其它壁纸或全局设置；没有记录时禁用。无需额外确认弹窗。
- **全局“恢复默认”**：保持既有设置reset行为，不顺手删除预设库。预设区说明删除是独立操作，防止用户误以为全局reset已清空预设。
- 对读取JSON、对象形状、ID和四项字段进行校验；只保留白名单字段，旧预设高亮度值按120新上限夹取。坏记录不影响原外观及其它合法预设，坏JSON或未知版本按无可用预设处理，不自动覆盖原始存储。
- 存储写入失败时不能显示保存/删除成功或清空既有记录；展示简短、可理解的失败状态。对外snapshot避免可变对象被调用者改写；不允许特殊对象键污染配置。

不要求建立预设数据库、Host路由、服务端同步或文件读写；普通本地设置足够。壁纸目录刷新不会自动删除暂时不在列表中的旧记录，避免移动/暂时离线后丢失预设。
