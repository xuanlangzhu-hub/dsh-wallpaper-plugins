## 实现

复用官方 active 会话的 scrollBody，使消息视口底边固定在卡片上沿。原 composerSeat 不移动 DOM，相对外层已定位 body 停靠；滚动条随消息视口结束在输入区上方。只裁消息，输入、工具栏/footer 和 portal 不被整层 mask。没有拦截滚轮、挪动 React 节点或增加黑罩。

原来是 JS 逐帧追赶随内容移动的 clip；同步 scroll 回调改善几何后画面仍漏字。新边界由浏览器原生 overflow 管理，停用该结构中的旧移动 clip，避免向下滚动时误遮正常内容。机制与 [Chromium 异步滚动](https://www.chromium.org/developers/the-rendering-critical-path/) 一致，但未对每个失败帧做完整合成 trace。输入包含块在滚动裁剪之外的依据见 [CSS 2.2 overflow](https://www.w3.org/TR/CSS22/visufx.html#overflow-clipping)。

ResizeObserver 随窗口/输入高度调整空间与宽度；原内联变量/属性保存并恢复，停止/卸载或离开 active 会话恢复官方 sticky。布局变化时原先在底部的滚动位置保持底部。仅对已识别的相对定位 body 启用；其它结构保留旧测量回退，不宣称通用兼容。图片/视频共享规则，顶部/区域开关/角点/侧栏与 Host 保留。
