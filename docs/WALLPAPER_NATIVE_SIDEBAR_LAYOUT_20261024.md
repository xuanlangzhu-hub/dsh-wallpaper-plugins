- 继承此前局部控件样式及宿主主题／透明度；没有新增外部依赖、全局overflow、窗口、版本或命令API。低频参数进一步收拢、对象小预览及作者初始未知状态的视觉表达留给后续小步，不能据此声称全部UI改版完成。

## 滚动与事件边界

冻结的正式宿主`dsh-client-ui-sidebar-right/lib/client.js`第1143行定义tabBody为高度100%、min-height:0、纵向flex且overflow:hidden；第1294–1298行是实际插槽正文承载。Whale根节点填满约束空间，仅自己的tabpanel使用overflow:auto、min-height:0及overscroll-behavior:contain。不修改宿主正文、其它页签或原文件页的滚动样式。

固定主控和壁纸内容各有自己的视图票据。主控随真实tab可见；媒体／预设内容只有在壁纸详情实际显示时可见。切界面或进图库会立即撤销内容票据，图片／视频文件对话框的旧结果不能在隐藏或返回后生效。它们仍沿用原控制器／Host门禁，没有绕过关闭证明或媒体限制。

分区／图库按钮在pointerdown先标记所属正文不可编辑，再发生焦点blur；作者输入的isCurrent检查所属区域，避免一次切页被误认成“确认输入”。随后原作者视图生命周期取消未完成编辑。正常完成编辑和已发送结果仍走既有事务通道，不回滚已发送参数、不重放未知结果。
