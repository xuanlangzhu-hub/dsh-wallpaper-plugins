# 更多外观：低频选项整理

2026-10-26。接续[常用分段选择与配色色块](WALLPAPER_NATIVE_UI_DIRECT_CHOICES_20261026.md)，本步完成“更多外观”内三组两项选择。日常DSH0.2.1-rc.3／Whalerc.48／GitBash0.1.2保持，未打包安装、操作DSH／WE或写运行设置，最终集中看整体效果。

## 变化

| Before | After | Why |
| --- | --- | --- |
| 侧栏层次下拉：均衡／稍深 | 直接点选：均衡／加深 | 选项少，展开列表没有必要；保留balanced／deep值 |
| 背景层次下拉：柔雾／清晰 | 两项直接点选 | 与前一步控件一致，保留soft／clear值 |
| 玻璃强度下拉：标准／克制 | 直接点选：标准／偏实色 | 说明实际变化，保留standard／restrained值 |
| 选项含义只藏在分区级title | 每个选项各有悬停提示和读屏描述 | 说明侧栏明度、主画布和浮层范围，默认不增加正文段落 |

“更多外观”仍默认折叠，原顺序、左侧不透明底色开关和错误摘要保持。三组复用前一步原生radio，鼠标／方向键立即选择、Tab进入每组当前项，同值不重复写入。标题、就近错误和禁用规则保持，不再引入保存／应用按钮。未改播放策略、作者参数、透明度或任何设置值的含义。

六条选项说明来自现有产品CSS范围核对：“加深”改变侧栏与会话区的明度关系；“清晰”改变主画布底色层次；“偏实色”提高浮层／菜单底色的实感，不改变输入卡片。说明不是实时预览，也不保证任意壁纸背景下主观效果相同。说明用普通文本的隐藏描述节点，与错误ID合并到radio的aria-describedby；无错误时只引用对应说明，错误出现／清除后仍保持对应关系。可见标签和✓保留，不仅靠颜色区分。
