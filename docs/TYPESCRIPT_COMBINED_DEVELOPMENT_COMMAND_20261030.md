# 分环境开发检查的单命令入口

2026-10-30。完成 FrameHub 实际接入后的开发检查编排，只新增 QA 工具，不修改运行源码或发行载荷。

## 使用

入口与说明：`dsh-whale-mist/qa/typescript-all/run.py`、同目录 `README.md`。

```powershell
python -X utf8 dsh-whale-mist/qa/typescript-all/run.py --compiler-root .tmp/ts-compiler-1 --cache .tmp/node24-types-1 --output .tmp/type-check-all-1
```

需要事先准备固定 TS 5.9.3 和真实 Node24／undici 声明缓存。缓存路径显式传入，输出必须全新；无需历史实验目录，本命令不联网、安装依赖或自动重试。

顺序运行原有 ES-only 与 Node Hub 入口，分别保留结果、文件图和日志。复用标准库 runpy，不另外生成一个外层 worker；临时派生真实 `common.Stages`，唯一变化是收紧 deadline，执行后恢复原执行器、参数、路径和工作目录。不替换编译器、声明、验证规则或运行实现。

保留每个 Node 阶段最多20秒、原入口80／75秒，再把跨入口160秒约束传到每个实际子进程。超时只处理直接持有的子进程，清理最多3秒；Python 本地文件核验与收尾不宣称有操作系统硬终止期限。前一套失败后不启动后一套，顶层结果区分 passed／failed／not-run，不把缺失收据或未知退出当成功。
