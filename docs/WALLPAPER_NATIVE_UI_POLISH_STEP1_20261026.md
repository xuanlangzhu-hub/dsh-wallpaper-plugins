## 本步结果

| Before | After | Why |
| --- | --- | --- |
| 两行对象信息加全宽强调色播放按钮 | 缩略图／单行标题／状态点与文字／32px播放或停止按钮／更换／更多的紧凑条；界面页进一步压缩 | 不让主控长期占据大块首屏，仍可辨认当前对象和状态 |
| 普通停止与开始都用大块主色 | 普通操作使用中性按钮，开始图标可用强调色；完整可访问名称与tooltip保留 | 降低视觉重量；清理失败时“重试清理”仍以文字直接显示，未塞进菜单 |
| 对象更多展开重复标题并挤动行；本地更多拉高相邻按钮 | 三处共用动作popover，不占正文流，菜单约束在当前侧栏边界内 | 打开不改变原按钮尺寸／正文位置；移除本地媒体的现有语义保持 |
| 右栏正文缺少一致衬底、顶部与正文有硬边 | 整个插件根节点只使用一次已有侧栏填充；header透明，未给正文／分组重复叠alpha | 直接沿用现有界面不透明度及主题投影，不新增透明度设置或一套固定颜色 |
| 关闭态开关边框／轨道接近壁纸 | 使用现有可读实色selector轨道、可见边框和主文字色滑块 | 不依赖亮壁纸内容辨认开关；不使用整个分组opacity削弱文字 |

窗口变窄时隐藏小预览，保留标题／状态和操作；标题单行省略但完整名称保留在title。关闭背景时明确显示“背景已关闭”，不继续只用“已停止”冒充来源状态。图片／视频来源本轮仅修更多菜单，未改成跨来源切换器。

动作菜单支持Enter／点击／上下键打开、上下／Home／End浏览、Escape关闭并回焦点、Tab离开和外点取消；与自绘选择器共用单一弹层占用。主题、目标、代次、来源、分区、可见性、会话／描述符变化使旧菜单失效。打开／取消不调用业务动作；菜单项仍调用原动作票据。未完成作者文本编辑时，pointerdown不让输入blur，菜单不打开、不提交旧输入。自己的监听和ResizeObserver随关闭／卸载释放，无轮询、计时器或新增UI依赖。
