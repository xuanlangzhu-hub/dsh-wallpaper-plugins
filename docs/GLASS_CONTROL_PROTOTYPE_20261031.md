## 用户选择：B 薄玻璃

用户实际看过样板后反馈「薄玻璃效果最好」。材质方向确定为 B，样板默认值同步为 B；A/C 保留为本轮对照证据，不继续扩展比较。此选择只确认材质方向，不等于已通过实际宿主验收。

接入时沿用 B 的局部 3px 模糊、120% 饱和、低不透明度透色和细边缘；压低投影与凸起感，保持已修正的字号／比例。整栏默认通透，毛玻璃仍为独立选项。B 是本地 CSS 方案，无需为此把 React 19 或 liquid-glass-react 加入插件。

下一步可定点做离线源码／固定底座 SDK 适配，不改播放或作者参数逻辑；不自动生成新候选、安装或提升日常。本轮仅记录选择、改样板默认值和同步接续，未改生产实现，无需重复行为测试。以下是试做时的历史记录。

## 真实库试接发现

1. npm 1.1.1 包 SHA-512 与 registry integrity 一致，MIT 全文已读，声明 React >=19；使用 React / ReactDOM 19.2.0 和独立 esbuild 0.25.11，依赖只落 `.tmp/glass-controls-prototype-20261031-a`。未升级宿主或给生产包加依赖。
2. 库首帧默认尺寸 270×69，且只监听 window resize，首次渲染／布局变更会产生过大的胶囊边缘。初版截图保留于 `.tmp/glass-controls-prototype-20261031-a/first-render`。样板用外层 ResizeObserver 转接尺寸事件、边界裁切和显式视觉层约束；上游包原字节未改。最终截图等实际 filter 宽度与控件宽度一致后再拍，没有把首帧错误当作稳定渲染结果。
3. C 小控件的边缘存在感比 A/B 强；B 较克制，A 较柔和，是本轮视觉观察，不替用户决定。库在 Electron／官方侧栏 SDK、真实视频背景、GPU 与动态长时成本均未验证；不能直接按此样板整体替换发行侧栏。
