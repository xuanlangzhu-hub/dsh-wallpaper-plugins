# Pixso UI 接入第一步：侧栏与控件样式（2026-10-30）

用户在设计补注完成后要求继续，确认下一步接入插件。本轮据此恢复离线 UI 实施，只完成第一步样式接入；不包含安装／打包／发布、动画、参数状态机或其他专项。

## 已接入

实现位置：`dsh-whale-mist/src/sidebar/native-appearance-sidebar.js` 的 `NATIVE_APPEARANCE_CONTROLS_CSS`，以及脚本同步的 `src/client.js` 对应生成片段。

- 侧栏使用13px字段字号、20px常规内边距、克制的分区线和24px背景模糊；底色仍来自宿主现有sidebar-fill，不另设固定紫色／不透明度，也未改左侧栏或标题栏。
- 壁纸画面字段和作者滑块改为标签／轨道／数值横排，保留现有输入元素、标签关联及事件处理。
- 开关统一32×18，保留关闭态边界；滑块14px手柄加2px主题强调色边框，配合键盘聚焦轮廓。
- 主题、强调色、可读性、侧栏／背景层次、玻璃强度采用紧凑字段行；配色色块改为小型色标。图库分页对齐新内边距，既有图库交互保持。
- 确认与未知反馈继续区分颜色，语义仍由原状态机决定；没有把状态板中的“已知未发送”示例写成通用错误条。
- 没有新增动画；原分段按钮按压缩放在本侧栏取消，避免视觉调整附带新的动态方案。

本轮应用 frontend-design 指南，但以已审 Pixso 稿和已有宿主组件为准。设计目标是壁纸之上的轻量原生设置栏，不新增装饰卡片、字体依赖、组件框架或页面。

### 几何夹具的实际范围

临时夹具从现有单测rig取服务结构，静态展开真实侧栏组件生成DOM，并在自有headless Edge测CSS。hooks、服务、作者字段及主题token取值是明确替身；没有运行官方SDK、React调度、真实播放、真实作者参数或完整popover生命周期。网络请求被阻止，未查询日常进程、端口或Profile。

首次几何检查错误地用 `getComputedStyle(range,'::-webkit-slider-thumb')` 断言UA手柄尺寸，Chromium返回了输入本体的88px宽度／0px边框。首轮失败日志、报告保留；第二版去掉这个不受支持的伪元素测量，不改产品源码，手柄外观通过实际截图核对。**16组通过不包含对UA手柄尺寸的计算样式证明。** 两轮自有浏览器均确认退出，未扩大期限。父监督45秒／51秒兜底，浏览器和各阶段另有短期限，无无限等待／自动重试。
