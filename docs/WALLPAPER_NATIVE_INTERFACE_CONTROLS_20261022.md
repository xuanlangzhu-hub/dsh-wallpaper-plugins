# 原生侧栏“界面”分区：不透明度与聊天底色

2026-10-22，接续[新旧编辑入口互斥](WALLPAPER_NATIVE_EDITOR_EXCLUSION_20261022.md)。本轮只迁入两个既有外观设置，不制作候选或操作日常应用。

## 布局和行为

当前壁纸、作者参数、播放选项和壁纸画面区保持；下方新增默认收起的原生`details`“界面”分区。展开后只有两行标签、百分比和滑杆，无保存/应用按钮或常驻成功说明，颜色和字体沿用原主题及RangeControl。

| 控件 | 原设置键与范围 | 行为 |
| --- | --- | --- |
| 界面不透明度 | `surface`，整数40–100，原默认82 | 复用原控制器及`--wm-ui-alpha`投影，调整有背景时的侧栏/卡片；菜单和输入卡片保持原不透明规则 |
| 聊天底色 | `chatBackdrop`，整数0–100，原默认0 | 复用`--wm-chat-alpha`与原`opaqueChat`联动；0保留壁纸，100使用主题实色，中间值保留主题底色混合标记 |

新控件不复制一套设置、投影或作者执行队列。普通修改调用同一同步controller setter，已有本地存储、主题更新、其它入口通知和错误后的权威值读取继续工作；相同值不重复写入。不发送播放、停止、作者属性或目录刷新命令。

没有当前播放源仍可调整界面设置；这不会自动开播。损坏/缺失的已存值禁用对应控件并显示“—”，不假装修复为默认。输入非整数、非数值或越界时拒绝，不从新侧栏静默夹紧。写入失败沿用短字段错误，另一项不受影响；异常发生在修改之后时保留实际值，不制造回滚或“已保存”承诺。

沿用前轮新旧页面互斥：旧通用页持有租约时，原生控件和迟到事件不能写入；关闭旧页后由原控制器恢复数值。原生dock与浮动副本共享数值，但折叠状态由各自原生details管理。切换图库不会清空界面设置。原`surface`仍在四字段外观预设范围内，本轮没有改其存取语义，也没有把聊天底色加入预设。

这是一个可展开分区的增量接入，尚不是“壁纸/界面”双页签导航或整体UI改版完成；真实透明度、文字对比和独立窗样式仍需后续受控验收。
