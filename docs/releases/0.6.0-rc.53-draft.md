# Whale Appearance 0.6.0-rc.53 — 首个预发行（草案）

Whale Appearance（鲸系外观）为DeepSeek Harness Windows Desktop提供主题和动态壁纸背景。这个版本先作为预发行提供，欢迎在保留原设置备份后试用。

## 功能

- 鲸雾／鲸渊主题，配色、强调色、文字可读性和透明度设置。
- 最右侧原生外观栏，壁纸预览图库、全年龄／敏感／成人分级筛选；默认仅全年龄。
- 点卡片只选择，点击“▶ 播放”才播放；支持播放中选另一张后显式切换，“壁纸参数”进入详情。
- 本地图片／视频背景；Wallpaper Engine scene、MP4 video和web集成，按已验证目标使用。
- 作者公开支持参数即时下发：Lucy粒子、非Lucy Float时钟关闭／恢复已有实际观察；不需要另点保存和应用。读取来源是作者声明或本机记录，不是WE当前值回读。

## 环境与安装

目前已验环境为Windows x64、DeepSeek Harness 0.2.1-rc.3。WE集成另外需要Wallpaper Engine、相应本地壁纸和.NET 10运行时；这些不包含在附件中。只使用本地背景时无需WE。

正式发布后，下载 `dsh-whale-mist-0.6.0-rc.53-windows-x64.zip` 及 `.zip.sha256`，核对校验值并解压。阅读其中 INSTALL.md、LICENSE 与第三方条款；不要把GitHub自动生成的Source code.zip当安装包。先正常退出DSH并备份当时Profile／外观设置，再用已配置的官方dsh命令安装解压后的tgz。例如：

```powershell
dsh plugin --profile desktop add .\dsh-whale-mist-0.6.0-rc.53.tgz
```

命令中的文件名以最终附件为准。重开后从顶栏“Whale 外观”进入侧栏，默认仅勾全年龄，手动选择播放。自动播放验证名单仍只有Lucy。项目代码为MIT；随包Microsoft组件按其单独SDK条款提供，完整原文位于ZIP的licenses目录。

## 已知限制

- 不是全部壁纸或全部作者参数都可用：application类型、条件参数、通用点击／鼠标转发和音频未完成验收。
- 三体实时演算的忽快忽慢在无采集源窗口中也出现，问题尚未解决。
- 源窗口初始可能短暂出现任务栏入口，未承诺始终隐藏。
- UI继续优化；滚动异常低优先级，曾记录宿主启动bad port错误，Restart恢复不等于根因解决。

本版本通过限定短验及一次日常切换确认，不作长期稳定或所有GPU／壁纸兼容承诺。遇到问题请提供版本、壁纸类型和复现步骤，分享日志前先去除账号、路径或会话内容。
