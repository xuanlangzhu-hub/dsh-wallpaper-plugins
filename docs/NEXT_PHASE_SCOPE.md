## 2. 候选方向

### A. 多壁纸兼容（建议先做）

**做什么**：把「只有一个硬编码 Lucy」变成「用户本机已装的壁纸可选并可用」。

- Host 侧只读扫描 Steam 工坊根目录，列出 `project.json` 的 `title` / `type` / 目录名；
  前端仍然只提交场景 id，**不能提交路径**。
- 白名单规则：只接受扫描根目录内的直接子目录，规范化后必须仍在根目录内；不存在的目录视为不可用。
- 逐类型验证：`scene`（16 个样本，与已验证路径同构）优先；`video`（7 个）与 `web`（1 个）
  需要确认走「开源窗口 + WGC 抓窗口」这条通道仍能出帧，否则在 UI 上标注「未验证类型」并可劝阻使用。

**为什么建议先做**：这是当前最影响日常使用价值的缺口，而且本机就有 24 个真实样本可覆盖，
成本主要在发现与校验，不需要重写采集。

**风险与未决**：

- 非 ASCII 标题（本机大量中文/日文名）在 JSON 输出与 UI 上的编码与显示。
- `video` / `web` 类型是否都经由 WE 自己的渲染窗口出帧，需要实测确认；不确定就必须诚实标注未验证。
- 扫描根目录允许配置（配置文件或环境变量），但要保证不变成「任意路径执行」。
- 24 个样本是否能代表其它机器上的类型分布，需要按「已验证类型」而不是「全部可用」来宣称。

### B. 长期常驻播放

**做什么**：把受监督预览变成可选常驻：取消/放宽 5 分钟上限、提供可选的开机自动播放、
验证长时间运行的稳定性与资源占用。

**风险与未决**：

- 资源占用：连接帧率与内存、GPU 占用需要长时间观测数据（如 30 分钟以上）。
- 交互副作用：DSH 最小化/失焦、系统休眠恢复、切换显示器与 DPI 变化。
- 需要新的清理语义：常驻意味着「不再自动停止」，用户如何预期停止、退出宿主如何保证清理。
- 与「受监督」的定位冲突：需要在 UI 上明确这是长期运行，而不是一次性预览。

### C. 去掉任务栏 / Alt-Tab 入口

**做什么**：换一种既能让 Windows Graphics Capture 抓到、又不留系统入口的窗口方式。

**已知约束**：`SW_HIDE` 与 `WS_EX_TOOLWINDOW` 会让 `CreateForWindow` 直接失败（HR `0x80070057`），
所以此前选的是「屏幕外 + 保留任务栏入口」。要做就得重新做原生侧窗口方式实验。

**风险**：可行性未证；这是原生侧实验，不能承诺结果。工作量中等偏大。

### D. 音频与鼠标交互

**做什么**：把 WE 场景的声音与鼠标响应接进来。

**风险**：范围最大。画面通道是「抓窗口像素」，音频与输入需要另设路径（音频捕获或合成、输入转发），
可能改变整个架构假设，建议在 A/B 之后再单独评估。

### E. 打包可复现性（低成本，可随任一批次顺带）

**做什么**：让干净检出能打出与归档一致的包。两个可选做法：

1. `.gitattributes` 定为 `* text=auto eol=lf`（会改变全仓库文本的检出行为，需一次规范化提交）；
2. 把 `assets/whale-icon-helper.exe` 也入库（+13 KB），使 `npm pack` 不依赖构建步骤。

**现状**：不改也能用——`docs/PROJECT_STATUS.md` 与插件 README 已记录「发布包以归档为准、交付时记录本次指纹」。

### F. 运行时依赖（可独立，也可并入 A）

**做什么**：评估自包含发布（把 .NET 运行时打进包），去掉「需要用户安装 .NET 10」的前置条件。

**风险**：包体积显著增加（预计 +60–80 MB），需要确认对插件安装与更新体验的影响。

## 4. 验收条件模板（每个批次都按这个结构定）

**无窗口检查**（不创建真实 WE 窗口，可在插件目录直接跑）：

- Host：发现/校验逻辑的单元测试（含路径越界、缺文件、非 ASCII 标题、类型标注）。
- 契约：`npm run test:sdk-contract` 保持通过；前端只能提交场景 id（沿用现有静态守卫思路）。
- 浏览器：隔离浏览器断言设置界面的场景列表、不可用原因、切换与持久化；原有 30 项与 99 项断言不回归。
- 包：`npm pack` 后记录 SHA256；包内文本文件与源码逐文件一致；helper 与 `qa/wallpaper-probe` 构建产物一致。

**实机验收**（用户点击、外部助手核验，DS 不操作鼠标、不退出宿主）：

- 场景：至少覆盖 1 个 `scene`、1 个 `video`，若 `web` 可用则加 1 个；每个都确认出帧、可读、
  停止后清理干净并保留原桌面壁纸。
- 长时：若做 B，至少一次 30 分钟以上的连续播放观察，记录帧率、内存与清理结果。
- 失败与边界：缺 .NET、场景被删除/移动、未验证类型的劝阻文案。
- 恢复：测试后回到日常版本与外观；Profile 四份文件与备份哈希一致；原 WE 进程身份不变。

**证据与记录**：

- 新检查写入独立目录，不覆盖历史证据；不使用通配符清理。
- 交付时必须写：相对上一版的变更、检查结果、包 SHA256、依赖与实测范围。
