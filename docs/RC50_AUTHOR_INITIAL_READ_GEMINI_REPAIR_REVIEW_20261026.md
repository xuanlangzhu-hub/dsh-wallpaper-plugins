## 待明日处理的具体问题

### 1. R2 迟到／销毁的成功声明超出断言（P2）

`sdk-diagnostic-test.mjs:435–472` 的 hidden-view-late-response 只等待固定60/100ms，未确认请求已经被拦截／释放／settle；主要断言是 additionalRequests <= 2，然后显式恢复。没有在隐藏后／重返后、手动恢复前断言旧错误不见，零请求也能满足该上界。恢复成功无法证明此前没有旧错误污染。

476–507的换代例先 stop、释放旧响应、等待100ms，再 start。没有把旧结果持续挂起到新代次已就绪，也没有检查旧结果是否曾进入状态；旧 payload 自身还是不合法／不同壁纸 schema，正常结构校验也可能拒绝。最后只有新粒子控件可用的断言，不能单独证明代次隔离。没有销毁／关闭侧栏时仍有未决请求的专项。

明日最小验收：用请求已拦截的 latch 替代靠等待猜测；旧请求挂起期间切换视图／启动新代次／销毁，记录请求数量与新上下文，再释放能够被正常结构校验接受的旧成功和旧错误。明确断言迟到结果不污染状态／DOM、不自动写入／重试；销毁后不得更新。只补相关窄组，不扩大全套。
