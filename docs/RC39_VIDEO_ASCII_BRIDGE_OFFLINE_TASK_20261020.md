# 下一项离线任务：受控ASCII媒体桥接（2026-10-20）

## 事实与范围

[中文路径与ASCII副本源观察](RC39_VIDEO_R3_ASCII_SOURCE_RESULT_20261020.md)：同一SHA256媒体，中文原路径可见无采集源为黑屏，WE日志打开失败且路径出现GBK→UTF8损坏；ASCII副本用户确认正常播放。副本同时换了目录和盘符，所以支持路径相关问题，尚未严格证明唯一编码转换边界。不能改成“所有编码/视频/采集已通过”。

下一项只做Host内部安全桥接的离线设计/实现与独立QA，不安装、开窗、采样、改系统codepage/codec/GPU、改WE全局设置或重新打旧rc.39。日常rc.38、开发manifest/assets rc.30、R1/R2补修和既有年龄/清理/身份门禁保持。用户正常使用电脑，离线工作不得操作日常DSH/WE。实现与Codex复审分开，先冻结输入，不直接交给外部CLI修改脏工作区。

## 实现要求

1. 只接Host重新核验通过的本地MP4 video。入口仍由原ID解析批准project/entry；前端不得提交媒体路径、缓存目录、命令或绕过年龄/清理/并发门禁。scene原路径不改变，Lucy-only自动播放名单不扩。
2. 先比较只读ASCII短路径与副本；无纯ASCII短名时不启用8.3、不改名/移动原文件。默认选择受控副本，不用可能把后续写入反映回原资产的硬链接作为捷径，不改Workshop内容。
3. 缓存根必须由Host选择，完整路径ASCII且位于当前用户可控的受限目录；若默认用户路径含非ASCII或无权限，明确失败，不擅自在系统盘根、Windows目录或宽权限公共路径找地方，不接受请求体替代根。
4. 每次播放用独立所有权/lease，固定ASCII媒体文件名，仅受控私有子目录。不覆写任意既有文件；拒绝链接/重解析点、路径穿越、大小写/物理路径漂移和不完整临时文件。客户端继续显示原ID/标题，不能把缓存副本登记成另一张壁纸。
5. 明确有限的单文件大小、总空间、并发与复制时间预算，未满足则返回可理解错误，不无界复制/重试。副本发布前完整校验字节数/SHA256；复制前后重新确认源文件身份/声明/大小/修改等，任何变化拒绝。不能把旧缓存当作重新验证的替代。
6. 复制/核验结束后、真正开源窗口前再服从同轮停止/卸载/启动代次。迟到结果不得启动；重启预检失败不得先关闭原活动源。最终helper获得受验证ASCII媒体路径；原entry/选择身份与bridge lease都保留在Host内部。
7. 生命周期随同一轮源/worker所有权；成功正常关闭并证明自有进程退出后才允许释放本轮自建缓存。关闭/退出未知、迟到任务可能仍持有时保留文件与报告，不能吞错报清理成功。删除必须局限于核验过的本轮owner目录，不删除原媒体、历史实测、固定候选或其它助手文件；不在状态轮询中做重复制/清理。
8. source URL/路径与内部错误不泄露到前端；日志按原隐私边界，前端给稳定错误代码与可执行提示。保留原播放模式、窗口尺寸/初始屏外策略、帧率/采集等待/设备选择和独立窗功能，不能把其它行为改变混入此修复。
9. 优先JS Host局部模块，不改已审原生程序/生产assets，不整体打开发工作区。需要原生改动时另列具体证据与差异，不能以当前含Trace开发二进制替换日常。

## 离线验收

- 真正产品模块：注册/verify→桥接准备→实际session/helper argv接缝完整链路，IO/进程只在明确底层替换；helper最终路径ASCII且内容与批准源相同，不只测试一个字符串替换函数。
- 源变化/声明变化/删除/链接/越界/非MP4/未批准根/分级隐藏仍拒绝；scene与Lucy原路保持。
- 缓存根Unicode/不可写/已占用/链接、空间/大小/时间预算、复制中止、错误hash/截断、并发start/stop/restart/unload、迟到复制结果、失败重启保护原活动源。
- 正常关闭释放自有lease；窗口/worker身份改变、退出未确认、关闭失败时保留，不杀原WE、不跨owner删除。清理负例必须穿过实际生命周期路径，不能只mock函数返回成功。
- 所有QA有阶段/总期限与外层watchdog，实际自有子进程退出证明。先离线纯替身，再相关Host/目录/独立窗回归；不为未改实现重复GPU/视觉长测。
- 清楚列出代码/底层IO替身/二进制/实机范围。离线通过后仍须另从固定基底最小整合新版本、核包，再取得当时方便确认做一次视频短验；本任务不预先授权安装。

交付需有输入指纹、独立输出、逐文件差异、命令/退出记录和未解决风险。未经独立复审不将产物提升到真实源码，不改版本、发布、推送或清理。
