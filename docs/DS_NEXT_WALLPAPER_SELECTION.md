## 用户操作约定（按此实现，不需要另行询问）

1. 打开 WE 设置区时按需加载列表，提供「刷新壁纸列表」。只浏览、刷新、选中都不启动或停止任何壁纸。
2. 列表显示名称、类型、可用状态和简短原因。scene 文件完整项允许手动实验；video/web/unknown/损坏项可见但不可启动。
3. Lucy 保留「已验证样例」标记；其它 scene 标「未验证，实验播放」。不要把文件完整写成兼容保证。
4. 没播放时，选择后点击「开始播放」。已经播放时，允许修改下一张选择，点击「重新开始」才实际切换。当前播放项与下一次选择分开显示，不让标题假装画面已经切换。
5. 重新开始先确认旧源已清理，再开新源。关闭未确认时禁止新建，停止/重试清理仍可用；不要绕开现有归属和操作串行约束。
6. 新场景启动失败时恢复普通主题、报告失败并清理本轮资源；允许用户手动选 Lucy 重试，不自动循环回退或重启。
7. 保存最后选择的 ID。刷新、外观参数变更、列表加载完成或重新挂载设置区都不触发播放。
8. 最后选择被删除/不支持时保留「所选壁纸已不可用」状态，禁用开始但保留刷新、选 Lucy 和必要的停止；不要悄悄替换并播放另一张。
9. 旧存储的 weScene="lucy" 保持兼容，不要求用户重新选择；语法合法的 catalog ID 不能因列表尚未加载就被 normalizeSettings 清掉。
10. 自动播放原有开关/下次启动语义保持。**未实机验证的库 scene 本轮只支持手动启动**：重开时不自动启动这类项，给简短说明；Lucy 的既有自动播放不回归。不要仅因一次运行成功就持久化为「已验证」。

## Host 接入要求

### 有界库与受限路由

- 复用 scanWallpaperCatalog({roots})，根目录只能由 Host 显式获准配置提供；本轮可用上述已核对的工坊根，保留可注入 roots 的 fixture 测试入口。无需全盘查找/自动搜 Steam，也不接受浏览器传入根目录。
- 复用已有 webServer 的认证路由机制。增加列表/刷新入口即可，确切路径由实现选择并记录；不要新增未认证的 HTTP 服务。
- 首次按需扫描并缓存，刷新显式触发；状态轮询/画面帧/每次 React render 不扫描。并发刷新合并或有界拒绝，不能排队无限扫描。
- 刷新成功后原子替换登记快照。失败/缺根/截断明确反馈，已有播放不被刷新打断，旧快照不能当永久路径授权。
- 前端返回 publicCatalogItem 这类受限结构，以及已验证样例/列表健康状态；不回传 project/entry/绝对路径、作者属性原文或目录错误中的私有路径。
- 作者名称必须按纯文本显示。无需提供缩略图读取路由，previewRef 可暂不使用。

### ID 到受限播放请求

- 浏览器只提交 ID、原有 mode/seconds；不能传 project、entry、目录、命令、窗口名字/句柄、helper 路径或其它原生参数。
- 兼容 legacy lucy 与 catalog 的 we-哈希 ID。用 Map 或自有属性核验，拒绝未知/伪造 ID（包含 __proto__/constructor），不能退到默认 Lucy 掩盖错误。
- 只允许获准根内、登记类型为 scene 且文件完整的记录进入实验播放。catalog 快照是索引；**每次启动前重新核验选中项目、元数据、内容文件及物理路径边界**，删除、换类型、越界或 junction 替换应拒绝。
- 保留 catalog 已有 scene.json 缺失时 scene.pkg 回退规则；不解包/执行作者文件，不把 scene 当普通视频。
- 在 Host 内把重新核验后的记录转换为当前播放请求，仍使用唯一源名字、现有 helper 与会话生命周期。禁止前端传路径后直接透传进 helper。
- 注意双层解析：registerWallpaperRoutes 里先 resolveSceneRequest；createPreviewSession.create 内部再次 resolveSceneRequest，默认仍是 SCENES。只改 routes 的 scenes 不够。需要一条受限的 Host 内部解析/注入通路，让最终启动、报告和当前 ID 一致；纯规则模块不得引入 Node fs 或被浏览器导入 catalog。
- 身份/路径/类型检查与异步扫描仍受现有 start/stop/dispose 取消约束：停止或卸载可打断待启动操作，晚完成的解析不得再开源；旧源清理未确认不能开新源。
- 刷新替换快照不改正在播放的会话配置。状态明确当前实际 sceneId，不能用前端下一次选择冒充当前画面。
- 保留未支持平台/缺 helper 的原提示，外观功能不因目录扫描失败崩溃。可用性不得继续仅依赖 Lucy 文件是否存在，否则库 scene 完整也启动不了。

## 前端要求

- 在现有 WE 场景下拉/列表位置局部扩展，提供刷新、加载/失败/空库/截断信息和不可用原因，中文为主，沿用现有中英文文案方式。
- 支持键盘选择；名称长时可截断或换行，完整名称可查看。窄窗口下标签横排可读，刷新和三个播放按钮清楚，不把停止挤成很小的独立行。
- 停止不能因为列表正在加载、所选项失效或刷新失败而失去操作入口；卸载时取消请求/丢弃迟到结果。
- 沿用 appearance.v1 存储和默认值，保留主题/配色/自动播放/区域开关等已有选择。只存稳定 ID，不把目录/作者数据写进前端外观存储。
- 初始 UI 不导入 Node 模块，不使用作者 HTML，不增加权限或任意文件选择路径入口。

## 必须验证的行为

用 fixture 和 fake session/helper，**不调用真实 WE/Native，不安装、不连接运行中的 DSH**。每项断言应验证行为，不只检查字符串/函数存在。

| 检查 | 必须满足 |
| --- | --- |
| 列表/刷新 | scene/video/web/损坏项独立；目录不存在、失败、截断明确；并发有界；状态轮询不扫描 |
| 数据边界 | public 不含绝对路径/作者属性；作者尖括号按文本；伪造 ID/任意路径拒绝，无 helper 调用 |
| 启动前重核验 | 删除文件、换类型、目录/文件换成 junction、越界声明拒绝；正常 scene.pkg 回退可解析 |
| 双层请求 | 非 Lucy fixture ID 真正传至最终 fake helper 参数与会话报告，不仅停留在 routes 返回值 |
| 切换 | A 播放→选择 B 不开窗→重新开始：关 A 成功后才开 B；失败清理/未知 ID 不无限重启 |
| 竞态 | 慢刷新/慢解析中 stop/dispose，迟到结果不开源；旧窗口关闭未确认，B 不启动，停止可重试 |
| 持久化 | lucy 旧值兼容；合法 catalog ID 重开保留；删除项提示；加载/刷新/参数变化不自动播放 |
| 自动播放 | 开关默认及既有 Lucy 语义不变；未验证 scene 重开不自动启动；手动停止后刷新/改外观不重启 |
| UI 与恢复 | 窄窗口列表/原因/刷新/停止可见；加载失败仍可停止；卸载取消/丢弃响应；原外观正常 |
